# Reference guide

The bibliography is embedded in `draft/main.tex`. `inventory.json` maps all
47 cited keys to canonical PDFs, preserved local-only files, or bibliography
records without an available portable PDF. Inclusion does not verify a claim.

Start with **Olver**, **Oliveri**, and **Tarayrah–Pitzel–Cheviakov** for the
regular-jet criterion, quotient charts, and the distinction between approximate
symmetry categories. The manuscript’s scalar source is **Paliathanasis–Leon–Leach**.

The canonical corpus contains 30 unique PDFs, one per SHA-256. Uncited reading,
duplicated uploads, book images and obsolete export inventories are preserved
outside the active tree; see [archive details](../docs/archive.md).
`ref/kb/` remains an ignored local collection; another checkout cannot depend on it.
