# Sources and BibTeX

- `../references.bib`: named research references used by the revised manuscript, with preserved citation keys, DOI/URL metadata where known, and local PDF fields where supplied.
- `archived_sources.bib`: a separate inventory record for every other archived PDF and discovered HTTP link. Its entries explicitly distinguish filename/URL inventory from verified bibliographic attribution.
- `pdf-citations.json`: every PDF in the package mapped to its BibTeX key.
- `link-inventory.json` and `LINKS.md`: URLs and the archived files in which they occur.
- `pdfs/`: all source PDFs from the project folder, including duplicate uploaded copies and earlier project PDFs.
- `images/`: supplied book-page scans. The book identity is not known; no book citation was invented.
- `code/repository/ref/` (from the package root): the public repository's unchanged PDF corpus.

The main bibliography loads both databases, but only cited research entries are printed.
An inventory record is not an endorsement of its scientific claims. In particular,
the supplied Navier--Stokes manuscript's title/author are recorded as supplied;
its theorem is not independently validated or transferred to SVE.

Bibliography verification during this export checked primary records for the
Nature Communications article, LieSolver v2, and the PMLR TM-PINN paper.
Other existing manuscript metadata was preserved, with unresolved publication
claims marked. Newly listed project PDFs use their title pages. See the download
status for optional additional public PDF copies.
