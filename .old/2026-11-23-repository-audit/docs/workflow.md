# Lie reduction of shallow-water and bed-evolution systems: a complete replication workflow

## 1. Mathematical principle, notation, and research scope

### 1.1 One-line representation of the complete principle

\[
\boxed{\mathfrak g_\Delta=\ker\mathscr D_\Delta\ \supset\ \mathfrak h\ \xrightarrow{\exp}\ H=\langle G_\epsilon\rangle\ \curvearrowright\ (\mathcal E_\Delta\cap\mathcal I_H^n)\ \xrightarrow{\pi_H^{(n)}}\ \overline{\mathcal E}_{\Delta,H}\subset J^n_{p-r}(M/H),\qquad \operatorname{Sol}_H(\Delta)\ \underset{\Gamma_F\mapsto\pi_H^{-1}(\Gamma_F)}{\overset{\Gamma_w\mapsto\Gamma_w/H}{\rightleftarrows}}\ \operatorname{Sol}(\overline{\mathcal E}_{\Delta,H}),\qquad p-r=1\ \Longrightarrow\ \overline{\mathcal E}_{\Delta,H}\text{ is an ODE system}.}
\]

The first operation determines equation-preserving vector fields. The second selects a local subgroup. The third projects invariant equation jets along group orbits. The last correspondence reconstructs invariant solutions from reduced solutions. These are different operations, with different inputs and verification requirements.

The count p−r=1 identifies one remaining independent variable. The reduced equations can still contain algebraic constraints or become identities; regular ODE evolution is established only after the leading-rank test in Section 3.1.

The diagram is a **local differential-geometric statement**, with algebraic determining calculations inside it. It is not a claim that an arbitrary nonlinear PDE or its orbit space is an algebraic variety. For polynomial or rational equations, parts of the calculation can be performed in a polynomial ring or its localization. Real powers and arbitrary constitutive functions require their declared smooth or analytic branches.

| Object | Definition and mathematical role |
| --- | --- |
| \(B\) | The base of independent variables; initially \(B\subset\mathbb R^2\), with coordinates \((t,x)\). The bed variable below is denoted \(b\), to avoid confusing it with the base. |
| \(M\) | The point space with independent and dependent coordinates; for the physical system, \(M\subset\mathbb R^2\times\mathbb R^3\), with coordinates \((t,x,h,u,b)\). |
| \(\Gamma_w\) | The graph \(\{(t,x,w(t,x))\}\) of a section \(w=(h,u,b)\). It is a two-dimensional submanifold of the five-dimensional point space. |
| \(J^n_p(M)\) | The extended jet space of \(p\)-dimensional submanifolds. On a graph chart it becomes the usual jet bundle \(J^n(M\to B)\). The extended notation makes the first diagram meaningful even before choosing a graph projection. |
| \(\mathcal E_\Delta\) | The equation submanifold defined by \(\Delta=0\) on a regular jet chart. Required differential consequences are included when the calculation needs higher jets. |
| \(\mathscr D_\Delta X\) | The linear determining operator \(\left.\operatorname{pr}^{(n)}X(\Delta)\right|_{\mathcal E_\Delta}\). Its kernel consists of admitted point generators when the infinitesimal criterion applies. |
| \(\mathfrak g_\Delta\) | The point-symmetry Lie algebra. A verified finite list need not span the full algebra. |
| \(\mathfrak h\), \(H\) | A selected finite-dimensional Lie subalgebra and the local group generated by its flows. For one generator, \(G_\epsilon=\exp(\epsilon X)\). This does not assert global completeness of the flow or surjectivity of a global exponential map. |
| \(r\) | The effective orbit rank on the selected regular chart. For graph reduction, it must equal the projected rank and satisfy \(r\le p\). It is not the number of generators in a redundant list. |
| \(\mathcal I_H^n\) | Jets of locally \(H\)-invariant submanifolds. In a regular transverse graph chart these are described by \(D_JQ_a^\alpha=0\), \(|J|\le n-1\). |
| \(\pi_H\), \(\pi_H^{(n)}\) | The orbit quotient on points and the corresponding projection on invariant jets. The latter is not defined by simply deleting coordinates from arbitrary, noninvariant jets. |
| \(\overline{\mathcal E}_{\Delta,H}\) | The reduced equation \(\pi_H^{(n)}(\mathcal E_\Delta\cap\mathcal I_H^n)\). Its actual order and number of independent residuals must be computed. |
| \(F\), \(\mathcal T_HF\) | The unknown reduced profile and its reconstruction as an original invariant field. |

The local action must be regular, the relevant equation intersection must have a usable defining chart, and the reconstructed submanifold must remain a graph in the original variables. On a projectable transverse chart, the diagram can be written with the ordinary quotient bundle \(\bar M\to\bar B\) and \(J^n(\bar M\to\bar B)\). A global smooth or Hausdorff quotient is not assumed. Olver develops the extended-jet correspondence in Proposition 3.34 and Theorem 3.36, and its graph-coordinate qualifications in Proposition 3.37 and Theorem 3.38 [1, printed pp. 230–235].

### 1.2 Research focus

The project studies **adaptive algorithm design, function iteration, and symmetry analysis** through the following concrete mathematical tasks.

1. **Symmetry analysis:** derive or verify transformations that preserve the chosen equations; distinguish these transformations from those fixing a particular solution graph; identify the parameter and rank strata where a reduction is usable.
2. **Adaptive algorithm design:** select among already verified representations, subgroups, first integrals, series orders, numerical methods, and approximation classes using chart margins, conditioning, error requirements, and measured total cost. Adaptation chooses a method; it does not replace its correctness test.
3. **Function iteration:** distinguish composition of exact group maps, iteration of an ODE integral operator, and updates of an optimization algorithm. They act on different spaces and have different convergence properties. Their explicit constructions appear below.

The reduction changes an unknown function of \(p\) variables into a restricted unknown function of \(p-r\) variables. It does not linearize a nonlinear PDE in general, solve arbitrary initial data, or automatically lower the differential order of the resulting ODE.

### Procedure 01. Specify the physical equations before searching for symmetry

**Purpose.** A symmetry belongs to a particular equation, constitutive law, and parameter convention. A transformation cannot be classified before these objects are fixed.

Take the shallow-water and evolving-bed system as the master model:

\[
\begin{aligned}
\Delta_1^{\mathrm c}&=h_t+(hu)_x=0,\\
\Delta_2^{\mathrm c}&=(hu)_t+
 \left(hu^2+\frac g2h^2\right)_x+ghb_x-\mathcal F(t,x,h,u,b)=0,\\
\Delta_3^{\mathrm c}&=b_t+
 \partial_x\mathcal Q(t,x,h,u,b)-\mathcal R(t,x,h,u,b)=0.
\end{aligned}
\tag{2.1}
\]

Here \(h\) is water depth, \(u\) is depth-averaged horizontal velocity, \(b\) is bed elevation, \(g>0\), \(\mathcal F\) is a specified momentum source, \(\mathcal Q\) is the effective sediment flux including any absorbed porosity factor, and \(\mathcal R\) is a specified bed source. The partial derivative in the third equation differentiates both explicit coordinate dependence and dependence through the fields.

On a smooth wet chart \(h>0\), subtract \(u\Delta_1^{\mathrm c}\) from the momentum residual. The product rule gives

\[
\begin{aligned}
(hu)_t&=u h_t+h u_t,\\
(hu^2)_x&=u^2h_x+2huu_x,\\
\left(\frac g2h^2\right)_x&=ghh_x,\\
u(hu)_x&=u^2h_x+uhu_x.
\end{aligned}
\]

Consequently,

\[
\Delta_2^{\mathrm c}-u\Delta_1^{\mathrm c}
=h\left(u_t+uu_x+gh_x+gb_x-\frac{\mathcal F}{h}\right).
\tag{2.2}
\]

Thus the primitive residuals are

\[
\begin{aligned}
\Delta_1&=h_t+uh_x+hu_x,\\
\Delta_2&=u_t+uu_x+gh_x+gb_x-\mathcal F/h,\\
\Delta_3&=b_t+\mathcal Q_hh_x+\mathcal Q_uu_x+
 \mathcal Q_bb_x+\mathcal Q_x-\mathcal R.
\end{aligned}
\tag{2.3}
\]

In the last line, \(\mathcal Q_x\) means the explicit partial derivative with fields held fixed. Equation (2.2) establishes equivalence on \(h>0\); it does not establish equivalence at a dry state.

The worked physical specialization throughout Procedures 08–16 is

\[
\mathcal F=\mathcal R=0,\qquad
\mathcal Q=\kappa u^m,\quad\kappa>0,\quad m\ge1,\qquad
\beta=m\kappa>0,\qquad u>0.
\tag{2.4}
\]

It gives \(b_t+\beta u^{m-1}u_x=0\). The positive-velocity branch is required for unrestricted real exponents. Other fluxes and sources use the same workflow but have their own determining equations.

The displayed master closure depends on point variables. A sediment law involving field gradients, diffusion, memory, or fractional operators changes the differential order or operator class; rebuild its jets and transformation rules rather than reusing the first-order matrix (2.16).

For d horizontal spatial coordinates, the corresponding master form is

\[
h_t+\nabla\cdot(h\mathbf u)=0,\quad
(h\mathbf u)_t+\nabla\cdot\left(h\mathbf u\otimes\mathbf u+\tfrac12gh^2\mathbf1_d\right)
+gh\nabla b=\boldsymbol{\mathcal F},\quad
b_t+\nabla\cdot\boldsymbol{\mathcal Q}=\mathcal R,
\]

where \(\mathbf u\), \(\boldsymbol{\mathcal Q}\), and \(\boldsymbol{\mathcal F}\) have d components and \(\mathbf1_d\) is the identity matrix. There are p=d+1 independent variables and q=d+2 fields. The detailed computations below use d=1 so that every step can be written out. For d=2, one regular projected orbit direction leaves two independent variables and thus a reduced PDE; an ODE requires effective projected rank two. Multiple chosen generators must close, and Frobenius straightens their orbit distribution rather than turning noncommuting generators into commuting coordinate fields.

**Output.** The equations, variables, constants, closure, domain, regularity, and posed data. The next procedure fixes scales so that parameter comparisons refer to the same mathematical family.

### Procedure 02. Nondimensionalize and distinguish the parameters

**Purpose.** A power \(u^m\), a derivative with respect to m, and a computational cost comparison depend on the chosen scales. Changing m changes the dimensions of a dimensional transport coefficient.

Choose \(L_*,U_*,H_*>0\) and put

\[
x=L_*X,\quad t=(L_*/U_*)T,\quad
h=H_*\bar h,\quad u=U_*\bar u,\quad b=H_*\bar b.
\]

For example,

\[
h_t=(H_*U_*/L_*)\bar h_T,\qquad
(hu)_x=(H_*U_*/L_*)(\bar h\bar u)_X,
\]

so both mass terms have the same common factor. The dimensionless coefficients are

\[
\bar g=\frac{gH_*}{U_*^2},\qquad
\bar\kappa=\frac{\kappa U_*^{m-1}}{H_*},\qquad
\bar\beta=m\bar\kappa.
\tag{2.5}
\]

Drop bars only after recording these definitions. Holding \(\bar\kappa\) fixed as m varies is different from holding \(\bar\beta\) fixed. For a dimensionless positive velocity v,

\[
\partial_m(v^{m-1})=v^{m-1}\log v,
\]

whereas writing \(\log u\) for an unnormalized dimensional velocity has no defined dimensional meaning.

Use separate symbols for model parameters \(\lambda\), initial/boundary-data parameters \(a\), a group parameter \(\epsilon\), and trainable parameters \(\theta\). None is interchangeable with another.

**Output.** A dimensionless model registry and parameter cells. The next procedure chooses a representation without silently changing the model.

### Procedure 03. Choose Eulerian or material coordinates and prove the conversion

**Purpose.** A useful representation may expose a scalar compatibility equation. Such a conversion is justified by the original conservation law and the inverse map, not by the name “Lagrangian.” It is also distinct from a variational action.

The physical master equations can be treated directly in \((t,x,h,u,b)\). A material representation is an optional route for the source-free mass equation. Define a local material label s by the one-form

\[
ds=h\,dx-hu\,dt.
\tag{2.6}
\]

The form is closed because

\[
\partial_t h-\partial_x(-hu)=h_t+(hu)_x=0.
\]

On a simply connected smooth neighborhood, a potential s therefore exists. Its Jacobian with t is \(s_x=h>0\), so the inverse function theorem gives \(x=\phi(t,s)\). Differentiate \(s(t,\phi(t,s))=s\):

\[
s_x\phi_s=1,\qquad s_t+s_x\phi_t=0.
\]

Using \(s_t=-hu\) and \(s_x=h\) yields

\[
\phi_s=1/h,\qquad \phi_t=u.
\tag{2.7}
\]

For any Eulerian field f and its pullback \(f^{\mathrm L}(t,s)=f(t,\phi(t,s))\), the chain rule is

\[
f_t^{\mathrm L}=f_t+\phi_t f_x,\qquad
f_s^{\mathrm L}=\phi_s f_x,
\]

hence

\[
f_x=\frac{f_s^{\mathrm L}}{\phi_s},\qquad
f_t=f_t^{\mathrm L}-\frac{\phi_t}{\phi_s}f_s^{\mathrm L}.
\tag{2.8}
\]

For the remainder of this scalar conversion, specialize to (2.4): the momentum and bed sources vanish and the transport law is the positive power law. General sources would retain their transformed terms and give a different compatibility equation. Write \(q=\phi_s>0\), \(v=\phi_t>0\), and \(b^{\mathrm L}(t,s)=b(t,\phi(t,s))\). From the primitive momentum equation,

\[
\begin{aligned}
u_t+uu_x&=\phi_{tt},\\
h_x&=\frac1q\partial_s(q^{-1})=-\frac{\phi_{ss}}{q^3},\\
b_x&=b_s^{\mathrm L}/q,
\end{aligned}
\]

so multiplication by q gives

\[
A+g b_s^{\mathrm L}=0,
\qquad A=q\phi_{tt}-g\phi_{ss}/q^2.
\tag{2.9}
\]

The Exner equation becomes

\[
b_t^{\mathrm L}-\frac vq b_s^{\mathrm L}+J=0,
\qquad J=\beta v^{m-1}\phi_{ts}/q.
\tag{2.10}
\]

Substituting \(b_s^{\mathrm L}=-A/g\) gives

\[
b_t^{\mathrm L}=-\frac{vA}{gq}-J.
\]

Mixed derivatives of the same bed function must agree:

\[
\begin{aligned}
\partial_t(-A/g)&=\partial_s\left(-vA/(gq)-J\right),\\
D_tA-D_s(vA/q)-gD_sJ&=0.
\end{aligned}
\tag{2.11}
\]

Define the model identifiers

\[
\boxed{E=\text{original Eulerian system},\quad
P:\ \mathscr E_P=D_tA-gD_sJ,\quad
M:\ \mathscr E_M=D_tA-D_s(vA/q)-gD_sJ.}
\tag{2.12}
\]

P is the printed scalar comparison model. M is the material compatibility equation derived from (2.1), (2.4). They differ by an advective contribution and must not share a certificate by assumption.

In this three-model contract, E denotes the source-free specialization (2.4) of the physical master system. Changing its closure or sources creates a new model record.

Conversely, an M-solution on a simply connected regular neighborhood gives the closed bed form

\[
\omega_M=\left(-\frac{vA}{gq}-J\right)dt-\frac Ag\,ds.
\tag{2.13}
\]

Its primitive reconstructs \(b^{\mathrm L}\) up to an additive gauge. Inverting \(x=\phi(t,s)\), and setting \(h=1/q\), \(u=v\), recovers the original equations. Bed data must agree with the same primitive. On a non-simply-connected domain, vanishing periods are an additional requirement. The analogous P-form lacks \(-vA/(gq)\) and reconstructs the printed two-equation model, not E.

This transformation uses a solution-dependent mass potential. It is not an ordinary invertible point transformation on the original five-dimensional point space; it does not automatically identify the Eulerian and material point-symmetry algebras.

The scalar mass-label form (2.6) is a one-spatial-dimensional construction. A multidimensional material map requires its own label coordinates and Jacobian equations; neither (2.6) nor \(h=1/\phi_s\) is copied unchanged into the d=2 system.

**Output.** A verified representation and reconstruction contract. The next step introduces the derivative coordinates needed to test its transformations.

### Procedure 04. Construct the jet coordinates and equation chart

**Purpose.** A point transformation acts on values and derivatives. Jet coordinates record the derivative data independently before an actual solution is chosen.

For \(w=(w^1,w^2,w^3)=(h,u,b)\), the first jet has coordinates

\[
(t,x,h,u,b,h_t,u_t,b_t,h_x,u_x,b_x).
\]

It has dimension \(2+3\binom{2+1}{1}=11\). In general, with p independent variables, q fields, and derivatives through order n,

\[
\dim J^n=p+q\binom{p+n}{n}.
\tag{2.14}
\]

This counts ambient coordinates, not solution-space dimension, number of symmetries, or algorithm runtime.

The count follows from mixed-partial symmetry. A derivative of exact order k corresponds to a multi-index \((j_1,\ldots,j_p)\) of nonnegative integers with \(j_1+\cdots+j_p=k\). There are \(\binom{p+k-1}{k}\) such indices. Summing from k=0 through n gives \(\binom{p+n}{n}\) derivative/value coordinates per field. For one field and two independent variables, the second-order list is \(w_{tt},w_{tx},w_{xx}\); \(w_{xt}\) is not an additional coordinate.

The integer coefficients in repeated product rules arise from the same combinatorics:

\[
D_t^aD_x^b(fg)=\sum_{i=0}^{a}\sum_{j=0}^{b}
\binom ai\binom bj
(D_t^iD_x^jf)(D_t^{a-i}D_x^{b-j}g).
\]

For example, \(D_tD_x(fg)=f_{tx}g+f_xg_t+f_tg_x+fg_{tx}\). These counts and product-rule multiplicities explain the combinatorial part of prolongation. They do not replace the real differential equations for generator coefficients.

The total derivative is defined by its action on a composed differential function:

\[
D_i R[j^{n+1}w]=\partial_{x^i}\{R[j^nw]\}.
\]

In coordinates,

\[
D_i=\partial_{x^i}+\sum_{\alpha,J}w^\alpha_{J+i}\partial_{w_J^\alpha}.
\tag{2.15}
\]

For example,

\[
D_x(hu_x)=h_xu_x+hu_{xx},\qquad
D_t(h^{-1})=-h^{-2}h_t.
\]

Write the primitive system as

\[
\Delta=w_t+\mathbf A(t,x,w)w_x-f(t,x,w)=0,
\tag{2.16}
\]

where

\[
\mathbf A=
\begin{pmatrix}
u&h&0\\g&u&g\\\mathcal Q_h&\mathcal Q_u&\mathcal Q_b
\end{pmatrix},
\qquad
f=\begin{pmatrix}0\\\mathcal F/h\\\mathcal R-\mathcal Q_x\end{pmatrix}.
\]

On this chart the principal time jets can be eliminated explicitly:

\[
w_t=f-\mathbf A r,\qquad r=w_x.
\tag{2.17}
\]

The three entries of r remain free jet coordinates. This independence permits coefficient splitting. It does not mean that the jet coordinate axes carry a preferred orthogonal geometry.

For the third-order scalar material equation, choose a leading jet only after checking its coefficient. The coefficient of \(\phi_{ttt}\) in P and M is q, so q>0 permits that elimination. The total derivatives in a prolongation calculation may temporarily require jets of one higher order; their cancellation or restriction must be performed explicitly [1, Definition 2.34 and Theorem 2.36, printed pp. 112–115].

**Output.** An ordered jet registry, independent residuals, a principal-jet substitution, and the remaining parametric jets. These determine where the symmetry identity must hold.

### Procedure 05. Define the general point generator and its flow

**Purpose.** The coefficients are unknown because the equation-preserving transformations have not yet been determined. They are not chosen from a convenient scaling table.

Start with

\[
X=\tau(t,x,h,u,b)\partial_t+\xi(t,x,h,u,b)\partial_x
+\eta^h(t,x,h,u,b)\partial_h
+\eta^u(t,x,h,u,b)\partial_u
+\eta^b(t,x,h,u,b)\partial_b.
\tag{2.18}
\]

For the scalar material representation, the same definition specializes to the three unknown coefficient functions

\[
X=\tau(t,s,\phi)\partial_t+\xi(t,s,\phi)\partial_s
+\eta(t,s,\phi)\partial_\phi.
\]

The field count changes the number of vertical coefficients; there is no separate principle for obtaining three coefficients rather than the five in (2.18). In both cases their equations come from prolongation and free-jet splitting.

A one-parameter local flow \(G_\epsilon\) is defined by

\[
\frac{d\bar t}{d\epsilon}=\tau(\bar t,\bar x,\bar w),\quad
\frac{d\bar x}{d\epsilon}=\xi(\bar t,\bar x,\bar w),\quad
\frac{d\bar w^\alpha}{d\epsilon}=\eta^\alpha(\bar t,\bar x,\bar w),
\qquad G_0=\mathrm{id}.
\tag{2.19}
\]

Local uniqueness gives

\[
G_{\epsilon+\delta}=G_\epsilon\circ G_\delta,
\qquad G_{-\epsilon}=G_\epsilon^{-1}
\]

where these compositions are defined. For instance, \(X=\partial_t\) integrates to \(G_\epsilon(t,x,w)=(t+\epsilon,x,w)\); \(X=x\partial_x\) integrates to \(x(\epsilon)=e^\epsilon x(0)\), not \(x+\epsilon\).

For a general point action, the transformed graph is a function only if the map from old base coordinates to transformed base coordinates along that graph has an invertible Jacobian. This graph condition is distinct from invertibility of the full point map.

**Output.** The general coefficient functions and the definition of the transformations they generate. Their derivative action is required next because the equations contain derivatives.

### Procedure 06. Derive prolongation from the chain rule

Let \(\bar x^i=x^i+\epsilon\xi^i+O(\epsilon^2)\) and \(\bar w^\alpha=w^\alpha+\epsilon\eta^\alpha+O(\epsilon^2)\). Differentiating the transformed graph gives

\[
D_i\bar w^\alpha=\bar w^\alpha_{\bar x^j}D_i\bar x^j.
\]

Insert

\[
D_i\bar w^\alpha=w_i^\alpha+\epsilon D_i\eta^\alpha+O(\epsilon^2),\quad
D_i\bar x^j=\delta_i^j+\epsilon D_i\xi^j+O(\epsilon^2),
\]

and \(\bar w^\alpha_{\bar x^j}=w_j^\alpha+\epsilon\eta_j^\alpha+O(\epsilon^2)\). The coefficient of \(\epsilon\) is

\[
D_i\eta^\alpha=\eta_i^\alpha+w_j^\alpha D_i\xi^j.
\]

Therefore

\[
\eta_t^\alpha=D_t\eta^\alpha-w_t^\alpha D_t\tau-w_x^\alpha D_t\xi,
\qquad
\eta_x^\alpha=D_x\eta^\alpha-w_t^\alpha D_x\tau-w_x^\alpha D_x\xi.
\tag{2.20}
\]

For example, the depth coefficient is explicitly

\[
\begin{aligned}
\eta_t^h={}&\eta^h_{,t}+\eta^h_{,h}h_t+\eta^h_{,u}u_t+\eta^h_{,b}b_t\\
&-h_t(\tau_{,t}+\tau_{,h}h_t+\tau_{,u}u_t+\tau_{,b}b_t)\\
&-h_x(\xi_{,t}+\xi_{,h}h_t+\xi_{,u}u_t+\xi_{,b}b_t).
\end{aligned}
\tag{2.21}
\]

Every symbol on the right is an ordinary partial derivative of a coefficient function or a standard field jet. A comma distinguishes, for example, \(\eta^h_{,t}\) from the prolonged coefficient \(\eta_t^h\).

Higher coefficients follow by repeating the same calculation:

\[
\eta_{J+i}^\alpha=D_i\eta_J^\alpha-w_{J+t}^\alpha D_i\tau-w_{J+x}^\alpha D_i\xi.
\tag{2.22}
\]

Equivalently, define the characteristic

\[
Q^\alpha=\eta^\alpha-\tau w_t^\alpha-\xi w_x^\alpha.
\tag{2.23}
\]

Then

\[
\eta_J^\alpha=D_JQ^\alpha+\tau w_{J+t}^\alpha+\xi w_{J+x}^\alpha.
\tag{2.24}
\]

For example,

\[
\begin{aligned}
D_tQ^h={}&D_t\eta^h-(D_t\tau)h_t-\tau h_{tt}
 -(D_t\xi)h_x-\xi h_{tx},\\
D_tQ^h+\tau h_{tt}+\xi h_{tx}
={}&D_t\eta^h-h_tD_t\tau-h_xD_t\xi.
\end{aligned}
\]

The apparent second jets cancel, giving (2.20). The same cancellation occurs at every order for a point generator. These are the coefficients derived by Olver's Theorem 2.36; the characteristic appears in his (2.48)–(2.50) [1, printed pp. 113–119].

In the scalar notation p=\(\phi_t\), q=\(\phi_s\), this gives the fully expanded first coefficients

\[
\begin{aligned}
\eta_t^{\rm pr}&=\eta_{,t}+(\eta_{,\phi}-\tau_{,t})p-\xi_{,t}q
-\tau_{,\phi}p^2-\xi_{,\phi}pq,\\
\eta_s^{\rm pr}&=\eta_{,s}-\tau_{,s}p+(\eta_{,\phi}-\xi_{,s})q
-\tau_{,\phi}pq-\xi_{,\phi}q^2.
\end{aligned}
\]

For example, the first line is obtained by expanding
\(\eta_{,t}+\eta_{,\phi}p-p(\tau_{,t}+\tau_{,\phi}p)-q(\xi_{,t}+\xi_{,\phi}p)\).
Second and third coefficients are obtained from (2.22), retaining the same partial-versus-prolonged distinction. This is the scalar calculation underlying the book's printed p. 117.

**Output.** An explicit prolonged vector field. It can now be applied to the equations without guessing derivative weights or omitting chain-rule terms.

### Procedure 07. Impose equation invariance before graph invariance

**Purpose.** A symmetry transforms solutions into solutions. It need not fix an individual solution. The two tests must be separated.

The infinitesimal equation test is

\[
\left.\operatorname{pr}^{(n)}X(\Delta_A)\right|_{\mathcal E_\Delta}=0
\quad\text{for every residual }A.
\tag{2.25}
\]

For a regular equation submanifold, this is tangency of the prolonged field. Its local flow then preserves that submanifold. To identify tangency with the full necessary solution-symmetry criterion, the relevant local-solvability conditions must also be checked [1, Theorem 2.71, printed p. 165]. An analytic solved form provides a route to local analytic solvability via Theorem 2.73; merely writing \(\Delta=0\) does not prove it.

For the source-free primitive equations, direct differentiation gives

\[
\begin{aligned}
\operatorname{pr}^{(1)}X\Delta_1
 &=\eta_t^h+u\eta_x^h+h\eta_x^u+\eta^u h_x+\eta^h u_x,\\
\operatorname{pr}^{(1)}X\Delta_2
 &=\eta_t^u+u\eta_x^u+g\eta_x^h+g\eta_x^b+\eta^u u_x,\\
\operatorname{pr}^{(1)}X\Delta_3
 &=\eta_t^b+\beta u^{m-1}\eta_x^u
 +\beta(m-1)u^{m-2}\eta^u u_x.
\end{aligned}
\tag{2.26}
\]

The last term comes from
\(X(u^{m-1})=(m-1)u^{m-2}\eta^u\). No derivative of m occurs because m is fixed during a group action. If the closure or source depends explicitly on coordinates, the corresponding \(X(\mathbf A)\) and \(X(f)\) terms must be retained.

Substitute (2.17) **after** constructing the prolongation. Do not impose \(Q=0\) here: doing so would test a conditional or nonclassical problem instead of the classical point-symmetry problem.

**Output.** An identity on independent parametric jets. The identity must hold for all their values, which leads to determining equations.

### Procedure 08. Collect the independent jet coefficients explicitly

**Purpose.** The prolonged criterion contains the unknown coefficient functions and free field derivatives. Since it holds for every permitted free jet, each independent polynomial coefficient must vanish.

The following collection treats the entire master system (2.16), rather than just a scalar illustration. Define

\[
\begin{gathered}
r=w_x,\quad k=f-\mathbf A r,\quad
\eta=(\eta^h,\eta^u,\eta^b)^T,\quad
\mathbf E=\eta_w,\\
\tau_w=(\tau_{,h},\tau_{,u},\tau_{,b}),\quad
\xi_w=(\xi_{,h},\xi_{,u},\xi_{,b}),\\
X\mathbf A=\tau\mathbf A_{,t}+\xi\mathbf A_{,x}
 +\sum_\alpha\eta^\alpha\mathbf A_{,w^\alpha},\quad
Xf=\tau f_{,t}+\xi f_{,x}+\sum_\alpha\eta^\alpha f_{,w^\alpha}.
\end{gathered}
\]

All matrices and rows are evaluated at \((t,x,w)\); k is a column, and row–column multiplication gives a scalar. The complete first prolongation residual is

\[
\begin{aligned}
\mathcal V(r)={}&\eta_{,t}+\mathbf E k
-k(\tau_{,t}+\tau_w k)-r(\xi_{,t}+\xi_w k)
+(X\mathbf A)r\\
&+\mathbf A\{\eta_{,x}+\mathbf E r
-k(\tau_{,x}+\tau_w r)-r(\xi_{,x}+\xi_w r)\}-Xf.
\end{aligned}
\tag{2.27}
\]

Substitute k and collect constant, linear, and quadratic powers of r:

\[
\mathcal V(r)=c+\mathbf L r+\mathcal N(r),
\tag{2.28}
\]

where

\[
\begin{aligned}
c={}&\eta_{,t}+\mathbf E f-f(\tau_{,t}+\tau_wf)
+\mathbf A\eta_{,x}-\mathbf A f\tau_{,x}-Xf,\\
\mathbf L={}&-\mathbf E\mathbf A+\mathbf A\mathbf E+X\mathbf A
+(\tau_{,t}+\tau_wf-\xi_{,x})\mathbf A\\
&-(\xi_{,t}+\xi_wf)\mathbf1+\tau_{,x}\mathbf A^2
+f(\tau_w\mathbf A)-(\mathbf Af)\tau_w,\\
\mathcal N(r)={}&-(\mathbf Ar)(\tau_w\mathbf Ar)
+r(\xi_w\mathbf Ar)
+(\mathbf A^2r)(\tau_wr)-(\mathbf Ar)(\xi_wr).
\end{aligned}
\tag{2.29}
\]

Here \(\mathbf1\) is the three-by-three identity matrix. In particular, \(f(\tau_w\mathbf A)\) is an outer product, not a scalar contraction.

For completeness, put \(a=\tau_w\mathbf A\) and \(d=\xi_w\mathbf A\). The symmetric quadratic coefficient is

\[
\begin{aligned}
S_{i,jk}={}&-\mathbf A_{ij}a_k-\mathbf A_{ik}a_j
+\delta_{ij}d_k+\delta_{ik}d_j\\
&+(\mathbf A^2)_{ij}\tau_{,w^k}
+(\mathbf A^2)_{ik}\tau_{,w^j}
-\mathbf A_{ij}\xi_{,w^k}-\mathbf A_{ik}\xi_{,w^j},
\end{aligned}
\]

so \(\mathcal N_i=\tfrac12\sum_{j,k}S_{i,jk}r_jr_k\). The determining equations are precisely

\[
c_i=0,\qquad \mathbf L_{ij}=0,\qquad S_{i,jk}=0
\quad(i,j,k=1,2,3;\ j\le k).
\tag{2.30}
\]

This gives 3 constant, 9 linear, and 18 quadratic scalar conditions before simplification and dependencies. These 30 coefficient conditions belong to this first-order three-field representation; they are not the 118 coefficients reported for a different third-order scalar expansion.

The conditions are linear in \(\tau,\xi,\eta\) and their derivatives. Products of known model coefficients and free jets do not make the determining system nonlinear in the unknown generator. Leibniz coefficients and mixed-derivative multi-indices are combinatorial bookkeeping; solving (2.30) is differential algebra over the reals. It is not a search through integer linear combinations.

For an autonomous source-free model, f=0 and \(\mathbf A=\mathbf A(w)\), so

\[
c=\eta_{,t}+\mathbf A\eta_{,x},\qquad
\mathbf L=-\mathbf E\mathbf A+\mathbf A\mathbf E
+\eta\cdot\partial_w\mathbf A
+(\tau_{,t}-\xi_{,x})\mathbf A-\xi_{,t}\mathbf1+\tau_{,x}\mathbf A^2.
\tag{2.31}
\]

As a first check, \(X=\partial_t\) makes every term vanish. With explicit time-dependent coefficients, the same substitution instead gives the conditions \(\mathbf A_{,t}=0\) and \(f_{,t}=0\); time translation must not be assumed in that case.

**Output.** Necessary determining equations with their branch conditions. The next procedure solves consequences, separates parameters before division, and verifies resulting candidates in the unsplit equations.

### Procedure 09. Solve determining consequences, separate strata, and certify candidates

**Purpose.** Coefficient collection produces equations for unknown functions. Solving those equations, rather than selecting convenient coefficients in advance, determines the admissible search space.

There is an instructive exact deduction for the positive source-free physical model (2.4). Its matrix is

\[
\mathbf A=\begin{pmatrix}u&h&0\\g&u&g\\0&\beta u^{m-1}&0\end{pmatrix}.
\]

The quadratic determining polynomial is simplest in an eigenbasis. To justify a real eigenbasis with distinct eigenvalues, seek a positive diagonal similarity \(\mathbf D^{-1}\mathbf A\mathbf D\) that is symmetric. Matching adjacent off-diagonal entries requires

\[
h\frac{D_2}{D_1}=g\frac{D_1}{D_2},\qquad
g\frac{D_3}{D_2}=\beta u^{m-1}\frac{D_2}{D_3}.
\]

Thus \(D_2/D_1=\sqrt{g/h}\) and \(D_3/D_2=\sqrt{\beta u^{m-1}/g}\). Choose \(\mathbf D=\operatorname{diag}(\sqrt h,\sqrt g,\sqrt{\beta u^{m-1}})\). Direct matrix multiplication gives

\[
\mathbf D^{-1}\mathbf A\mathbf D=
\begin{pmatrix}
u&\sqrt{gh}&0\\
\sqrt{gh}&u&\sqrt{g\beta u^{m-1}}\\
0&\sqrt{g\beta u^{m-1}}&0
\end{pmatrix}.
\tag{2.32}
\]

The off-diagonal entries are positive. This real symmetric tridiagonal matrix has simple eigenvalues: if the first component of an eigenvector were zero, successive rows would force all components to vanish; otherwise its first component determines all remaining components recursively. Each eigenspace therefore has dimension one, and symmetric diagonalizability gives three distinct real eigenvalues.

At a fixed point, express the free vector r in that eigenbasis, with eigenvalues \(\lambda_1,\lambda_2,\lambda_3\). This is a pointwise basis change in the coefficient polynomial, not an assertion that a global change of dependent variables diagonalizes the PDE. Write the transformed rows \(\tau_w\) and \(\xi_w\) as a and d in this paragraph only. The quadratic polynomial in (2.29) becomes

\[
\mathcal N_i=r_i\sum_j
(\lambda_i-\lambda_j)(\lambda_i a_j-d_j)r_j.
\tag{2.33}
\]

For \(i\ne j\), its coefficient is zero only if \(d_j=\lambda_i a_j\). For a fixed j there are two distinct choices of \(i\ne j\), so

\[
(\lambda_i-\lambda_k)a_j=0
\quad\Longrightarrow\quad a_j=d_j=0.
\]

Consequently, on this positive regular model chart,

\[
\tau_w=\xi_w=0,
\qquad \tau=\tau(t,x),\quad\xi=\xi(t,x).
\tag{2.34}
\]

This is a derived projectability restriction, not an initial assumption. It does not determine the remaining functions \(\tau,\xi,\eta\), and it is not a maximal classification. The zero-transport and dry/zero-velocity branches require separate analysis; the argument cannot be transferred to a different sediment law without checking its matrix.

The positive power-law coefficients are analytic, and the system is solved for \(w_t\). Analytic initial functions with arbitrary prescribed admissible values and spatial slopes therefore supply local analytic solutions by the Cauchy–Kovalevskaya result cited in Procedure 07. This supplies the local-solvability link needed to treat the free first-jet splitting as necessary for this model, rather than as an unexplained formal test.

As a transparent **candidate calculation**, restrict the remaining search to diagonal scalings

\[
X_\omega=\omega_t t\partial_t+\omega_x x\partial_x
+\omega_h h\partial_h+\omega_u u\partial_u+\omega_b b\partial_b,
\]

where the five \(\omega\)'s are constant real weights. They are not derivatives. For a derivative, its weight equals field weight minus differentiated-coordinate weight. Balancing the mass terms gives

\[
\omega_h-\omega_t=\omega_h+\omega_u-\omega_x
\quad\Longrightarrow\quad\omega_u=\omega_x-\omega_t.
\]

Balancing primitive momentum terms gives

\[
\omega_u-\omega_t=2\omega_u-\omega_x
=\omega_h-\omega_x=\omega_b-\omega_x,
\]

so \(\omega_h=\omega_b=2\omega_u\). Finally, the Exner terms require

\[
\omega_b-\omega_t=m\omega_u-\omega_x.
\]

Insert the preceding relations:

\[
2\omega_u-\omega_t=(m-1)\omega_u-\omega_t
\quad\Longrightarrow\quad(3-m)\omega_u=0.
\tag{2.35}
\]

Do not divide by \(3-m\) before splitting the cases. For \(m\ne3\), this candidate calculation leaves \(\omega_u=0\) and \(\omega_x=\omega_t\). For m=3, choose \(\omega_t=0\), \(\omega_x=1\), giving

\[
\boxed{S=x\partial_x+2h\partial_h+u\partial_u+2b\partial_b.}
\tag{2.36}
\]

This choice normalizes a real scaling line; it does not impose an integer-weight theory.

Return to the full primitive residuals. Their prolonged weights give the exact identities

\[
\operatorname{pr}^{(1)}S\Delta_1=2\Delta_1,\qquad
\operatorname{pr}^{(1)}S\Delta_2=\Delta_2,\qquad
\operatorname{pr}^{(1)}S\Delta_3
=2\Delta_3+(m-3)\beta u^{m-1}u_x.
\tag{2.37}
\]

Thus S is admitted at m=3. On the conservative system the three multipliers are respectively 2, 3, and 2. This sufficient check is separate from the restricted search that suggested S. It proves the candidate's validity, not completeness of the diagonal or full point algebra.

The general task at this stage is to integrate the full determining equations, preserving arbitrary-function families and exceptional factors. If that integration is incomplete, report a verified subset or an unresolved classification. For the separate printed scalar model P, the uploaded dissertation reports a complete local positive-chart calculation with four generators for \(m\ne1,3\) and five at m=1 and m=3 [D, Section 8.3]. That result is not a classification of E or M.

**Output.** Verified generators with model and parameter labels, plus an explicit classification-coverage status. Selecting a useful subgroup now becomes a geometric and data-dependent problem.

### Procedure 10. Form Lie subalgebras and understand the optimal-system operation

**Purpose.** A reduction uses a subgroup, so selected fields must close under the Lie bracket. An optimal system removes conjugate subgroup choices; it does not classify all PDE solutions.

For vector fields \(X=X^i\partial_i\), \(Y=Y^i\partial_i\), define

\[
[X,Y]^i=\sum_j\left(X^j\partial_jY^i-Y^j\partial_jX^i\right).
\tag{2.38}
\]

At m=3, the autonomous source-free physical equations admit

\[
T=\partial_t,\qquad P_x=\partial_x,\qquad Z=\partial_b,\qquad S.
\]

Direct differentiation gives

\[
[S,P_x]=-P_x,\quad[S,Z]=-2Z,\quad[S,T]=0,
\]

and the translation brackets vanish. These verified fields form a subalgebra; no assertion is made that they are the full algebra.

There are now **two different orbit spaces**:

- A physical point orbit \(H\cdot(t,x,h,u,b)\) in M, used for reducing independent variables.
- An adjoint orbit of a line \(\mathbb R X\) in the Lie algebra, used for classifying subgroup choices.

Use Olver's pushforward convention

\[
\operatorname{Ad}_{G_\epsilon}Y=(G_\epsilon)_*Y
=Y-\epsilon[X,Y]+\frac{\epsilon^2}{2}[X,[X,Y]]-\cdots.
\tag{2.39}
\]

The opposite sign convention is also used in the literature, so the convention must accompany a table. For example,

\[
\operatorname{Ad}_{\exp(\epsilon P_x)}S=S-\epsilon P_x,
\qquad
\operatorname{Ad}_{\exp(\delta Z)}S=S-2\delta Z.
\]

Therefore \(aS+bP_x+cZ+dT\), with a nonzero, can locally be simplified by choosing \(\epsilon=b/a\) and \(\delta=c/(2a)\). This is an example of coefficient simplification under conjugacy, not a complete optimal system.

A one-dimensional subalgebra is a line, so X and \(cX\), c nonzero, select the same local orbit distribution. Its coefficients are real, not necessarily integral. An optimal system is a list of conjugacy-inequivalent such lines with the stated coverage [1, Definition 3.11, printed p. 206]. One verified subgroup is sufficient for one reduction; completing an optimal system is needed only for the corresponding coverage claim. Fixed data and chart domains can reduce the admissible conjugacy group.

**Output.** A selected verified Lie subalgebra and, when required, a justified conjugacy-coverage statement. The next test determines whether its point orbits can lie in solution graphs compatible with the task.

### Procedure 11. Check orbit rank, graph transversality, and posed data

For generators \(X_a=\xi_a^i\partial_{x^i}+\eta_a^\alpha\partial_{w^\alpha}\), compute

\[
r_{\mathrm{tot}}=\operatorname{rank}[\xi_a^i,\eta_a^\alpha],
\qquad
r_{\mathrm{base}}=\operatorname{rank}[\xi_a^i].
\tag{2.40}
\]

For the regular transverse graph construction require
\(r_{\mathrm{tot}}=r_{\mathrm{base}}=r\), constant on the chosen chart. For S, the base row is \((0,x)\), so both ranks are one on x>0. There is one remaining independent variable. At a rank change, use another chart or analyze a different branch.

By contrast, Z has total rank one but projected rank zero. Its bed characteristic is \(Q^b=1\), which cannot vanish. It is a valid equation symmetry but has no fixed three-field graph under pure bed translation. Verticality does not make it an invalid symmetry; it makes this invariant-graph construction unavailable.

Data must be checked separately. If a boundary is \(\rho(t,x)=0\), preservation of that boundary requires \(X\rho=0\) there. A data condition \(C(t,x,w^{(k)})=0\) also requires its prolonged tangency condition on the data set.

For initial data at t=t0, S preserves the initial line because \(St=0\). Its field conditions are

\[
2h_0-xh_0'=0,\qquad u_0-xu_0'=0,\qquad2b_0-xb_0'=0.
\]

Integrating on x>0 gives

\[
h_0(x)=H_0x^2,\quad u_0(x)=a_0x,\quad b_0(x)=C_0x^2.
\tag{2.41}
\]

For example, \((h_0/x^2)'=(xh_0'-2h_0)/x^3=0\), so the first ratio is constant. Arbitrary random functions do not satisfy these equations. At a fixed boundary x=L>0, \(S(x-L)|_{x=L}=L\ne0\), so the full fixed-domain IBVP is not S-invariant. One may still restrict an already constructed invariant solution to that domain and supply its boundary traces; this is a constructed solution, not invariance of the arbitrary fixed-boundary problem. See also [2, Section 6.4, printed pp. 161–162].

**Output.** A regular graph chart and compatible-data description, or a precise rejected/unsupported branch. The accepted subgroup can now be integrated to obtain its orbits.

### Procedure 12. Integrate the group flow and construct the point quotient

For S, (2.19) becomes

\[
\bar t'=0,\quad\bar x'=\bar x,\quad
\bar h'=2\bar h,\quad\bar u'=\bar u,\quad\bar b'=2\bar b,
\]

where primes in this paragraph mean differentiation in \(\epsilon\). With initial point \((t,x,h,u,b)\), the linear flow equations give

\[
G_\epsilon(t,x,h,u,b)
=(t,e^\epsilon x,e^{2\epsilon}h,e^\epsilon u,e^{2\epsilon}b).
\tag{2.42}
\]

The orbit is the set of these points as \(\epsilon\) varies over its permitted interval. It is a curve of related point configurations, not a solution trajectory in physical time: t stays fixed in this example.

To remove the flow direction, seek functions I with \(SI=0\). Direct differentiation gives

\[
S(t)=0,\quad S(h/x^2)=0,\quad S(u/x)=0,\quad S(b/x^2)=0.
\]

Define the orbit coordinate and invariant coordinates by

\[
y=\log x,\quad z=t,\quad
v_h=h/x^2,\quad v_u=u/x,\quad v_b=b/x^2.
\tag{2.43}
\]

Since the variables are dimensionless, \(\log x\) is defined on x>0. In dimensional notation use \(\log(x/L_*)\). We have \(Sy=1\) and \(Sz=Sv_h=Sv_u=Sv_b=0\). The inverse is

\[
t=z,\quad x=e^y,\quad h=e^{2y}v_h,
\quad u=e^yv_u,\quad b=e^{2y}v_b.
\]

The forward base Jacobian in the order \((z,y)\) is \(1/x\); the fibre Jacobian is \(\operatorname{diag}(x^{-2},x^{-1},x^{-2})\). Thus the full forward determinant is \(x^{-6}\ne0\), and the inverse determinant is \(x^6\).

Distinguish the maps

\[
\pi_0(t,x,h,u,b)=(t,x),\qquad
\pi_H(t,x,h,u,b)=(t,h/x^2,u/x,b/x^2).
\tag{2.44}
\]

The first sends an orbit to a curve in the base. The second sends the whole orbit to a single point. For example:

| Point in M | Base projection \(\pi_0\) | Orbit quotient \(\pi_H\) |
| --- | --- | --- |
| \((0,1,1,1/2,1/5)\) | \((0,1)\) | \((0,1,1/2,1/5)\) |
| \(G_{\log2}(0,1,1,1/2,1/5)=(0,2,4,1,4/5)\) | \((0,2)\) | \((0,1,1/2,1/5)\) |

The fibre/orbit correspondence is explicit. If two points have the same four quotient coordinates, choose \(\epsilon=\log(x_2/x_1)\). The ratio equalities force \(h_2=e^{2\epsilon}h_1\), \(u_2=e^\epsilon u_1\), and \(b_2=e^{2\epsilon}b_1\). They are therefore on the same orbit. Conversely, substitution of (2.42) leaves every quotient coordinate unchanged.

**Output.** An explicit local quotient, an inverse chart, and checked Jacobians. The quotient still contains arbitrary field values; selecting a graph in it produces the invariant ansatz next.

### Procedure 13. Derive the invariant graph rather than guessing an ansatz

On the graph \(w=w(t,x)\), define \(C^\alpha(t,x,w)=w^\alpha-w^\alpha(t,x)\). Acting with X gives

\[
X(C^\alpha)|_{\Gamma_w}
=\eta^\alpha-\tau w_t^\alpha-\xi w_x^\alpha
=Q^\alpha.
\]

Thus \(Q=0\) means that X is tangent to this graph. Local uniqueness of the flow shows that tangency preserves the graph locally. This is the geometric reason for the invariant-surface condition.

For S the three equations are

\[
2h-xh_x=0,\quad u-xu_x=0,\quad2b-xb_x=0.
\]

For fixed t, integrate the ratio derivatives exactly as in (2.41):

\[
\partial_x(h/x^2)=\partial_x(u/x)=\partial_x(b/x^2)=0.
\]

The integration constants may depend on the invariant variable t. Hence

\[
\boxed{h=x^2H(t),\qquad u=xa(t),\qquad b=x^2C(t).}
\tag{2.45}
\]

Equivalently, in quotient coordinates the invariant graph is
\((v_h,v_u,v_b)=(H(z),a(z),C(z))\). It is a curve in the four-dimensional quotient. Its inverse image under \(\pi_H\) is a two-dimensional surface, and the checked graph projection makes it the original three-field graph.

The construction retains three unknown functions, each of one variable. It removes dependence on the orbit coordinate y from the invariant field ratios. It does not assert that h itself is constant along the orbit; h scales by \(e^{2\epsilon}\).

At order n, impose \(D_JQ=0\), \(|J|\le n-1\), when describing invariant jets. These derivative conditions are automatic for an explicitly differentiated invariant ansatz, but must be included in a jet-elimination implementation [1, Theorem 3.38, printed pp. 233–235].

**Output.** A motivated, integrated invariant graph with the correct number of remaining variables. It is still only a candidate solution until the original equations are substituted.

### Procedure 14. Pull back every derivative and substitute into every original equation

For (2.45), all first derivatives are

\[
h_t=x^2H',\quad h_x=2xH,\quad
u_t=xa',\quad u_x=a,\quad
b_t=x^2C',\quad b_x=2xC,
\tag{2.46}
\]

where now primes mean differentiation in t. Compute the conservative products explicitly:

\[
\begin{aligned}
hu&=x^3Ha,& (hu)_x&=3x^2Ha,&(hu)_t&=x^3(H'a+Ha'),\\
hu^2+gh^2/2&=x^4(Ha^2+gH^2/2),&&&\\
\partial_x(hu^2+gh^2/2)&=4x^3Ha^2+2gx^3H^2,&&&\\
ghb_x&=2gx^3HC.&&&
\end{aligned}
\]

For general m the bed flux derivative is

\[
\partial_x\{\kappa(xa)^m\}=\kappa m x^{m-1}a^m
=\beta x^{m-1}a^m.
\]

At the admitted cubic stratum m=3, substitution gives

\[
\begin{aligned}
\Delta_1^{\mathrm c}[\mathcal T F]
 &=x^2(H'+3aH),\\
\Delta_2^{\mathrm c}[\mathcal T F]
 &=x^3\{aH'+Ha'+4Ha^2+2gH^2+2gHC\},\\
\Delta_3^{\mathrm c}[\mathcal T F]
 &=x^2(C'+\beta a^3).
\end{aligned}
\tag{2.47}
\]

Define

\[
R_1=H'+3aH,\quad
R_2=a'+a^2+2g(H+C),\quad
R_3=C'+\beta a^3.
\]

The middle line is

\[
\begin{aligned}
aR_1+HR_2
&=aH'+3a^2H+Ha'+Ha^2+2gH(H+C)\\
&=aH'+Ha'+4Ha^2+2gH^2+2gHC.
\end{aligned}
\]

Thus the full residual identity is

\[
\Delta^{\mathrm c}[\mathcal T F]=
\begin{pmatrix}
x^2&0&0\\x^3a&x^3H&0\\0&0&x^2
\end{pmatrix}
\begin{pmatrix}R_1\\R_2\\R_3\end{pmatrix}.
\tag{2.48}
\]

The determinant is \(x^7H\), nonzero on x>0, H>0. Consequently every original residual vanishes **if and only if** every reduced residual vanishes on this chart. A nonzero scalar multiplier or a full-column-rank matrix is needed for this conclusion; a singular or empty residual list cannot certify it.

**Output.** An exact equation-pullback identity and its nonzero factors. This establishes the local PDE/ODE equivalence inside the chosen invariant class.

### Procedure 15. State the actual ODE problem and solve a controlled exact example

The reduced system is

\[
\boxed{H'=-3aH,\qquad a'=-a^2-2g(H+C),\qquad C'=-\beta a^3.}
\tag{2.49}
\]

It is a first-order system of three ODEs, with a polynomial vector field. The independent-variable count fell from two to one. No further ODE order reduction was used. An IVP requires \((H,a,C)(t_0)\); its analysis is developed in Section 3.

To illustrate an exact solution search, define \(T=t-t_* >0\) and try

\[
H=kT^{-2},\qquad a=\alpha T^{-1},\qquad C=dT^{-2}.
\]

This is an additional power-law candidate within the verified ODE class, not a consequence of the preceding Lie quotient. Its motivation is that every term in each ODE then has the same power of T. Substitution, before division by unknown constants, gives

\[
(-2+3\alpha)k=0,\qquad
-\alpha+\alpha^2+2g(k+d)=0,\qquad
-2d+\beta\alpha^3=0.
\]

On k>0 the first equation gives \(\alpha=2/3\). The third gives \(d=4\beta/27\). The second then gives

\[
-\frac29+2g(k+d)=0,
\qquad
k=\frac{1}{9g}-\frac{4\beta}{27}
=\frac{3-4g\beta}{27g}.
\]

Therefore, for \(0<4g\beta<3\), an exact smooth physical solution on x,T>0 is

\[
\boxed{
h=\frac{3-4g\beta}{27g}\frac{x^2}{T^2},\qquad
u=\frac{2x}{3T},\qquad
b=\frac{4\beta}{27}\frac{x^2}{T^2}.}
\tag{2.50}
\]

Translations can restore an arbitrary admissible spatial origin and bed gauge after checking their data. Direct substitution into all three conservative equations verifies (2.50); these checks are included in Appendix A. This is a pedagogical exact member of the derived invariant class, with no novelty or arbitrary-data claim.

It differs from the report's independently constructed class \(h=H(t)\), \(u=a(t)x\), \(b=b_*+C(t)x^2\), whose mass equation is \(H'=-aH\), not \(-3aH\). The two classes must not share ODE coefficients or stability constants by assumption.

**Output.** A concrete ODE system, its data requirements, and an independently checked exact control. A general ODE solution need not have this power form.

### Procedure 16. Reconstruct the physical fields, data, and balances

**Purpose.** An ODE calculation becomes a PDE solution only after reconstruction and verification in the original variables.

For any admissible solution of (2.49), reconstruct (2.45). Verify x>0 and H>0. As long as a remains finite on a finite interval,

\[
H(t)=H(t_0)\exp\left(-3\int_{t_0}^{t}a(\tau)\,d\tau\right)>0
\]

when \(H(t_0)>0\). Positivity follows on that interval; global continuation or boundedness of a does not follow from this formula.

On a bounded interval \([x_1,x_2]\), with \(0<x_1<x_2\), the water mass is

\[
\mathcal M(t)=\int_{x_1}^{x_2}h\,dx
=\frac{x_2^3-x_1^3}{3}H(t).
\]

Then

\[
\mathcal M'(t)=-(x_2^3-x_1^3)aH
=-(hu)(t,x_2)+(hu)(t,x_1).
\tag{2.51}
\]

It is not generally constant because the interval has boundary flux. Likewise,

\[
\frac d{dt}\int_{x_1}^{x_2}b\,dx
=\frac{x_2^3-x_1^3}{3}C'
=-\kappa a^3(x_2^3-x_1^3)

### 2.19 Worked scalar packet C: why Equations (30)–(31) integrate

**Motivation.** A traveling subgroup of the printed scalar model combines translations. Let

\[

where c,d are fixed real constants. Its flow is

\phi=dt+F(z),\quad z=s-ct,\quad

The full derivative substitution is

\[
\begin{aligned}

\phi_{tt}&=c^2C,&\phi_{ts}&=-cC,&\phi_{ss}&=C,\\
\phi_{ttt}&=-c^3K,&\phi_{tts}&=c^2K,&
\phi_{tss}&=-cK,&\phi_{sss}&=K.
\end{aligned}
\]

On profile functions, \(D_t=-cD\), \(D_s=D\). Hence

\[
A=(c^2P-g/P^2)C,\quad J=-\beta c v^{m-1}C/P,
\]

and the printed residual is

\[
\mathscr E_P[\phi]=-cD\{\mathcal B(P)C\},\qquad
\mathcal B(P)=c^2P-g/P^2-g\beta(d-cP)^{m-1}/P.
\tag{2.71}
\]

For c nonzero, P>0, v>0, \(\mathcal B\ne0\), expansion gives

\[
\mathcal B(P)P''+\mathcal B'(P)(P')^2=0.
\tag{2.72}
\]

The coefficient derivative is

\[
\mathcal B'(P)=c^2+\frac{2g}{P^3}
+g\beta\left\{\frac{c(m-1)v^{m-2}}P+\frac{v^{m-1}}{P^2}\right\}.
\]

Where P is nonconstant and locally invertible, set \(\Xi=P(z)\), \(M(\Xi)=P'(z)\). Then

\[
P''=\frac{dM}{d\Xi}\frac{d\Xi}{dz}=M_\Xi M.
\]

Substitution into (2.72) gives

\[
\mathcal B(\Xi)M_\Xi M+\mathcal B'(\Xi)M^2=0.
\]

On the additional branch M nonzero, divide by \(\mathcal B M\):

\[
M_\Xi+\frac{\mathcal B'}{\mathcal B}M=0.
\]

Multiply by \(\mathcal B\) and use the product rule:

\[
\frac{d}{d\Xi}(\mathcal BM)=\mathcal BM_\Xi+\mathcal B'M=0.
\]

Therefore

\[
\boxed{\mathcal B(\Xi)M(\Xi)=I_0,\qquad M(\Xi)=I_0/\mathcal B(\Xi).}
\tag{2.73}
\]

This is the complete integration mechanism behind the corrected (30)–(31) transition. It is the integrating-factor solution of a linear first-order equation, not an unexplained power ansatz. The first integral \(\mathcal B(P)P'=I_0\) can also be obtained from (2.71) without using P as the independent variable, which preserves the constant-P branch.

Define the primitive

\[
Y(P)=\int^P\mathcal B(\rho)\,d\rho.
\]

Then

\[
\frac{dY(P(z))}{dz}=\mathcal B(P)P'=I_0,\qquad
Y(P(z))-Y(P_0)=I_0(z-z_0),\qquad
F=F_0+\int_{z_0}^{z}P(\zeta)\,d\zeta.
\tag{2.74}
\]

Since \(Y_P=\mathcal B\ne0\), this change is locally invertible. Equation (2.72) becomes \(Y''=0\). It is therefore already locally equivalent to the free-particle equation. For example, its eight point generators in \((z,Y)\) can be chosen as

\[
\partial_z,\ \partial_Y,\ z\partial_Y,\ z\partial_z,\ Y\partial_Y,
\ Y\partial_z,\ z^2\partial_z+zY\partial_Y,
\ zY\partial_z+Y^2\partial_Y.
\]

They pull back using \(\partial_Y=\mathcal B(P)^{-1}\partial_P\). Their verification reduces on \(Y''=0\) to

\[
\eta_{zz}+(2\eta_{zY}-\xi_{zz})Y'
+(\eta_{YY}-2\xi_{zY})(Y')^2-\xi_{YY}(Y')^3=0.
\]

For the last generator, for example, \(\eta_{YY}=2\) and \(\xi_{zY}=1\), so its quadratic coefficient is zero; the other coefficients vanish as well. Rediscovering these classical symmetries is not a new order-reduction result.

For m=3, c=-1, d=0, retain the positive velocity v=P rather than taking fractional powers of a negative c. Put \(a_*=1-g\beta\). Then

\[
\mathcal B(P)=a_*P-g/P^2,\qquad
Y(P)=\frac{a_*}{2}P^2+\frac gP.
\]

Multiplying (2.74) by P gives a cubic algebraic equation for P at each z when \(a_*\ne0\); at \(a_*=0\) its degree drops and that branch is retained separately. If \(I_0\ne0\), the remaining F quadrature is also explicit in P:

\[
\frac{dF}{dP}=\frac{P\mathcal B(P)}{I_0}
=\frac{a_*P^2-g/P}{I_0},
\]

\[
F-F_0=\frac{a_*}{3I_0}(P^3-P_0^3)
-\frac g{I_0}\log(P/P_0).
\tag{2.75}
\]

Equations (2.74)–(2.75) give a real, guarded parametric representation; an explicit algebraic branch for P must still be selected. If \(I_0=0\) and \(\mathcal B\ne0\), then \(P'=0\) and F is affine. If c=0, the original **P** pullback in (2.71) is an identity and must be analyzed before division. Zeros of \(\mathcal B\) are separate branches. No conclusion about model M or full E follows merely from solving this P-specific equation.

## 3. Analyze the ODE and identify precise ML interfaces

### 3.1 Determine what differential problem actually remains

After substitution, first retain the undivided equation

\[

\]

and any accompanying algebraic constraints. Check the Jacobian with respect to the proposed highest derivatives. If it is invertible, the implicit function theorem gives a local normal form. If it is singular, the result may require an algebraic branch analysis, a differential-algebraic treatment, another independent variable, or a lower-order equation. It is not automatically a failed PDE solution.

For a regular scalar third-order profile, define the first-order state

\[
Y=(F,P,C),\qquad Y'=f(z,Y)=(P,C,R(z,F,P,C)).
\tag{3.1}
\]

The initial vector is \((F_0,P_0,C_0)\). For a first-integral two-state version, its constant I0 must be fixed from that same initial vector. A BVP is a different problem: matching the number of boundary conditions is necessary but does not establish existence, uniqueness, or a nonsingular linearized boundary operator.

#### A complete local IVP existence/uniqueness argument

Choose a closed tube
\(T=[z_0,z_0+b]\times\overline{B_R(Y_0)}\)
inside the regular domain. Suppose the actual right-hand side is continuous there, bounded by M, and Lipschitz in Y with constant L. These bounds are to be checked from the equation; for the polynomial system (2.49), bounded Jacobian entries on a finite box provide them.

On the complete space of continuous curves in the ball, with the supremum norm, define the Picard operator

\[
(\mathcal PY)(z)=Y_0+\int_{z_0}^{z}f(\zeta,Y(\zeta))\,d\zeta.
\tag{3.2}
\]

If bM≤R, then

\[
\|(\mathcal PY)(z)-Y_0\|
\le\int_{z_0}^{z}\|f(\zeta,Y(\zeta))\|\,d\zeta
\le bM\le R,
\]

so \(\mathcal P\) maps this space to itself. For two curves,

\[
\begin{aligned}
\|\mathcal PY-\mathcal PZ\|_\infty
&\le\sup_z\int_{z_0}^{z}
 \|f(\zeta,Y(\zeta))-f(\zeta,Z(\zeta))\|\,d\zeta\\
&\le bL\|Y-Z\|_\infty.
\end{aligned}
\]

Choose bL<1. The contraction theorem gives a unique fixed point. Continuity of f makes that point continuously differentiable, and differentiating (3.2) gives the IVP. This proves local existence and uniqueness on a sufficiently small interval. Continuation requires the trajectory to remain in the equation domain; approaching a zero of L in (2.59) is not covered by this proof.

For (2.49), the Jacobian is

\[
D_Yf=\begin{pmatrix}
-3a&-3H&0\\-2g&-2a&-2g\\0&-3\beta a^2&0
\end{pmatrix}.
\]

On a box, an infinity-norm Lipschitz bound is the maximum of
\(3|a|+3|H|\), \(4g+2|a|\), and \(3\beta a^2\), with each bounded over the box. This belongs to the new invariant class (2.45). The report's value 19/5 belongs to its different uniform-depth affine class and is not copied here.

For an analytic normal form, analytic data give a local analytic solution. Olver's Theorem 2.73 supplies the analytic existence statement through its ODE specialization; the explicit Lipschitz reasoning above supplies the uniqueness argument used here [1, printed p. 166]. Analyticity on a positive real-power branch does not imply analytic continuation across zero velocity or a singular denominator.

### 3.2 Search for exact expressions in a declared expression class

The phrase **closed form** must specify an allowed grammar. A useful reporting convention distinguishes:

| Result class | What must be supplied |
| --- | --- |
| Explicit elementary/algebraic expression | The expression, its real/complex branch, and direct residual/data verification. |
| Expression using named special functions | The defining function class and domain, with a checked substitution. |
| Implicit equation or quadrature | The integral/implicit relation and the local inversion conditions; no false claim of an elementary explicit solution. |
| Convergent series | A coefficient recurrence, initial data, and a justified local convergence statement or radius/remainder bound when one is claimed. |
| Formal or asymptotic series | Its formal order and residual/truncation status, without an unproved convergence claim. |
| Numerical approximation | The method, domain, tolerance/refinement evidence, residual/data tests, and uncertainty. |

Apply the following exact-analysis order.

1. Integrate any already verified total derivative or first integral. Equations (2.55) and (2.71) provide concrete examples.
2. Use an admitted ODE symmetry to lower order, or a checked invertible change to a known equation. Packet C gives the local transformation \(P\mapsto Y(P)\) to \(Y''=0\).
3. Test motivated polynomial, power, exponential, or other finite expression families by exact coefficient substitution. Equation (2.50) illustrates a successful power balance; it does not imply that all solutions have that form.
4. If a finite exact representation is not found, construct a convergent local series or a verified numerical solution. Record “not found in the searched class,” not “no closed-form solution exists.”

An ML classifier can prioritize these branches, but a class label does not prove that a representation exists. Its positive prediction must return a candidate that passes the corresponding exact test. A negative prediction normally means unrecognized; an impossibility conclusion needs a theorem for a specified equation and expression class. There is no universal closed-form guarantee supplied by Lie reduction.

### 3.3 Reduce ODE order by a symmetry or a first integral

#### ODE symmetry route

For a scalar ODE, begin with another unrestricted point field

\[
Z=\zeta(z,F)\partial_z+\psi(z,F)\partial_F.
\]

Its prolongation is again constructed by (2.22), now with one independent variable. Verify

\[
\left.\operatorname{pr}^{(n)}Z(\mathcal R)\right|_{\mathcal R=0}=0.
\]

On a regular chart choose canonical coordinates r(z,F), s(z,F) satisfying
\(Zr=0\), Zs=1, and a nonzero coordinate Jacobian. Along a solution graph,

\[
\nu=\frac{ds}{dr}
=\frac{s_z+s_FF'}{r_z+r_FF'}.
\tag{3.3}
\]

The denominator must be nonzero. In canonical variables the prolonged equation is independent of the translation coordinate s, so replacing its derivatives by \(\nu,d\nu/dr,\ldots\) removes one order. Reconstruction supplies
\(s=s_0+\int\nu\,dr\), followed by inversion of the point chart. This is the mechanism described in [2, Sections 5.4.1–5.4.2, printed pp. 117–122].

For Z=\(\partial_F\), take r=z, s=F. Then \(\nu=F'\), precisely the first reduction in Packet B. Fixed graphs under \(\partial_F\) do not exist, but the derivative quotient is valid. Do not impose a new Q=0 at every ODE order-reduction step. An ODE symmetry may move the numerical initial value F0; transport the data and restore its integration constant rather than rejecting the symmetry merely for doing so.

#### First-integral route and the proposed learned object

For (3.1), a first integral is a nonconstant differentiable function \(I(z,F,P,C)\) satisfying the identity

\[
\boxed{\mathcal D_z I
=I_z+P I_F+C I_P+R I_C=0}
\tag{3.4}
\]

throughout the declared open normal-form chart. It is not enough that I vary little on one sampled solution.

If \(I_C\ne0\), the implicit function theorem locally solves \(I=I_0\) for C, giving an order-lowering equation with \(I_0=I(z_0,F_0,P_0,C_0)\). A proposed new integral must also be independent of already known integrals: the rank of their differentials must increase on an open regular set. For example, if \(I_1=LC\) is known, \(I_1^2\) has zero derivative too, but
\(d(I_1^2)=2I_1\,dI_1\), so it adds no independent integral.

For Packet A,

\[
I=LC,\quad I_C=L,
\]

and (2.57) gives

\[
\mathcal D_zI=(L_z+PL_F+CL_P)C+LR=0.
\]

Thus the order reduction is exact on L nonzero. The integral is already known analytically; learning it again is not a new discovery. A learner proposing an expression for a different reduced equation must pass (3.4), the independence test, the nonzero implicit-function derivative, and reconstruction/data checks.

Numerical neural weights do not by themselves supply an exact symbolic identity. A useful learned proposal pipeline returns a finite symbolic candidate, verifies its denominator branches, clears only permitted denominators, and checks the remaining identity independently. An approximate conserved quantity is reported as approximate and cannot be used as an exact first integral without an error analysis.

Flow-box coordinates can theoretically express local constants for a regular first-order flow. Computing those coordinates can already require solving the ODE. Abstract existence of local invariants therefore does not establish a cheap closed-form integral or an advantage for symbolic regression.

#### Infinite-dimensional symmetry

Keep arbitrary-function families symbolically rather than enumerating an infinite basis. For example, the heat equation admits \(X_f=f(t,x)\partial_u\), with the condition \(f_t=f_{xx}\). Identifying this ideal leaves the problem of finding f. The member \(\partial_u\) has Q=1 and no fixed scalar graph. A finite subgroup with a usable projected rank may still be selected from a larger algebra.

A generalized evolutionary characteristic depending on higher jets requires the linearized test

\[
\ell_\Delta(Q)=\sum_{\alpha,J}
\frac{\partial\Delta}{\partial w_J^\alpha}D_JQ^\alpha=0
\]

on the equation and its differential consequences. This differs from the point-coefficient determining problem. Infinitely many jet coordinates, an infinite-dimensional point algebra, and a generalized-symmetry hierarchy are different objects. None alone proves closed-form general solvability.

### 3.4 Construct the series, its recurrence, and its actual status

For a regular third-order normal form \(F'''=R(z,F,F',F'')\), write \(\xi=z-z_0\) and

\[
F=\sum_{j\ge0}a_j\xi^j,\qquad
a_0=F_0,\quad a_1=P_0,\quad a_2=C_0/2.
\]

Termwise differentiation gives

\[
F'''=\sum_{n\ge0}(n+3)(n+2)(n+1)a_{n+3}\xi^n.
\]

For \(F_{n+2}=\sum_{j=0}^{n+2}a_j\xi^j\), matching the coefficient of \(\xi^n\) yields

\[
\boxed{a_{n+3}=\frac{[\xi^n]R(z_0+\xi,F_{n+2},F_{n+2}',F_{n+2}'')}
{(n+3)(n+2)(n+1)}.}
\tag{3.5}
\]

Only the already computed coefficients occur on the right at that order. At n=0,
\(a_3=R_0/6\). Differentiate the normal form once along its solution:

\[
F''''=R_z+R_FF'+R_PF''+R_CF'''
=R_z+P R_F+C R_P+R R_C.
\]

Therefore

\[
a_4=\frac1{24}(R_z+P_0R_F+C_0R_P+R_0R_C)_0.
\tag{3.6}
\]

The two initial-jet rows of Packet A consequently give

\[
\begin{aligned}
F_P(1+\xi)&=2+\tfrac12\xi+\tfrac1{20}\xi^2-\tfrac{11}{2370}\xi^3+O(\xi^4),\\
F_M(1+\xi)&=2+\tfrac12\xi+\tfrac1{20}\xi^2+\tfrac{49}{4335}\xi^3+O(\xi^4).
\end{aligned}
\tag{3.7}
\]

These are local expansions of different models. A degree-N polynomial constructed by (3.5), N≥3, cancels normal-form residual coefficients through order N−3. Its residual is generally \(O(\xi^{N-2})\), while its errors in F, F', F'' are respectively \(O(\xi^{N+1})\), \(O(\xi^N)\), \(O(\xi^{N-1})\) on an analytic solution. A nonzero leading-factor multiplication preserves these local orders; a singular factor can change them.

There are three separate questions: whether the recurrence is algebraically correct, whether the infinite series converges, and how accurately a finite truncation approximates the chosen solution on the reported interval. Analytic local existence answers the second locally. A quantitative radius or finite-interval error requires further bounds. Evaluating a truncated series numerically does not turn it into a global exact solution.

For the three-state polynomial ODE (2.49), a first Taylor step is

\[
\begin{aligned}
H&=H_0-3a_0H_0\xi+O(\xi^2),\\
a&=a_0-[a_0^2+2g(H_0+C_0)]\xi+O(\xi^2),\\
C&=C_0-\beta a_0^3\xi+O(\xi^2).
\end{aligned}
\]

For example,

\[
\begin{aligned}
H''&=-3a'H-3aH'\\
&=3(a^2+2g(H+C))H+9a^2H\\
&=12a^2H+6gH(H+C),
\end{aligned}
\]

which fixes the quadratic coefficient as half this value at the initial point. These equation-derived coefficients are distinct from coefficients supplied only by data lifting.

### 3.5 Compute numerical solutions and understand function iteration

#### Exact group composition

For a local symmetry flow, \(G_\epsilon^{\circ k}=G_{k\epsilon}\) when all intermediate maps exist. Its parameter is the group parameter, not necessarily physical time. S in (2.42) keeps physical t fixed.

#### Picard iteration

Starting with the constant curve \(Y^{[0]}=Y_0\), define
\(Y^{[k+1]}=\mathcal P Y^{[k]}\) using (3.2). The contraction estimate proves convergence on its stated interval. For (2.49), the first iterate is exactly the three linear Taylor expressions just displayed. This iteration acts on a space of functions, not on point configurations in M.

#### Time stepping

A Runge–Kutta step constructs stage slopes and an updated state:

\[
k_i=f\left(z_n+c_i\delta,Y_n+\delta\sum_j a_{ij}k_j\right),\qquad
Y_{n+1}=Y_n+\delta\sum_i b_ik_i.
\tag{3.8}
\]

For an explicit method, only previously computed stages appear. An embedded estimate guides the next step size. A typical controller balances an error model \(\mathrm{err}\approx C\delta^{p+1}\) with the tolerance, suggesting a factor proportional to \((\mathrm{tol}/\mathrm{err})^{1/(p+1)}\); actual solvers use their specific estimators and safeguards. This numerical map approximates the solution flow and is generally not an exact Lie symmetry.

Use DOP853 for appropriate smooth nonstiff high-accuracy IVPs, and assess Radau or BDF where stiffness warrants an implicit method. LSODA supplies automatic Adams/BDF switching. Record the installed version, tolerances, Jacobian treatment, failed steps, and event margins [4]. `solve_bvp` treats a separately posed two-point BVP, with the required number of conditions and its own solvability issues [5]. Do not change the problem type to improve a comparison.

#### Chebyshev representation and reuse

Map \([a,b]\) to \([-1,1]\) by \(\zeta=(2z-a-b)/(b-a)\). Define
\(T_j(\cos\theta)=\cos(j\theta)\), and approximate

\[
F_N(z)=\sum_{j=0}^{N}c_jT_j(\zeta(z)),\qquad
\frac d{dz}=\frac2{b-a}\frac d{d\zeta}.
\tag{3.9}
\]

In an interpolation/reuse method, accurate reference values determine the coefficients. In ODE collocation, the coefficients are unknowns constrained by the ODE and data. Those are different algorithms and costs. For a scalar third-order IVP with N+1 coefficients, for example, three initial traces and N−2 independent residual collocation equations give the matching number of conditions; solvability of that nonlinear algebraic system must still be assessed.

Compare derivative errors and the original undivided residual, not only function values. Interpolation, integration, and differentiation can have very different conditioning. A sparse set of collocation points is not a continuous residual enclosure.

#### Adaptive choice

The adaptive algorithm should first choose a regular model/reduction chart, then a representation and numerical method. It can adjust step size, series order, polynomial degree, chart patches, or a correction budget. A guard failure returns to a representation/branch decision; it must not be passed through as an ordinary time step. Repeated numerical or optimizer updates require their own stability or convergence analysis.

#### A derived hybrid profile architecture

On an already verified reduction, define

\[
\widehat F_\theta=P_K(z;\lambda,a)
+\chi_K(z;\lambda,a)N_\theta(z;\lambda,a).
\tag{3.10}
\]

The fixed analytical part \(P_K\), the lifting factor \(\chi_K\), the neural output, the data vector, and the parameter domain must be specified separately. For a third-order IVP, write \(\xi=z-z_0\) and use

\[
P_2=F_0+P_0\xi+\tfrac12C_0\xi^2,\qquad
\widehat F_\theta=P_2+\xi^3N_\theta.
\tag{3.11}
\]

The correction derivatives are

\[
\begin{aligned}
(\xi^3N)'&=3\xi^2N+\xi^3N',\\
(\xi^3N)''&=6\xi N+6\xi^2N'+\xi^3N'',\\
(\xi^3N)'''&=6N+18\xi N'+9\xi^2N''+\xi^3N'''.
\end{aligned}
\]

The first three data traces are therefore exact for any sufficiently smooth N, but the third derivative is not fixed by data alone. If \(R_0\) is supplied by the verified ODE, the alternative
\(\widehat F=P_2+R_0\xi^3/6+\xi^4N_\theta\)
also fixes the equation-derived third trace. This is the distinction between data lifting and an additional equation-derived prior.

For a reconstructed invariant field, exact geometric structure can hold for all weights. For example,

\[
\widehat\phi=\widehat F_\theta(st^2)
\quad\Longrightarrow\quad
-t\widehat\phi_t+2s\widehat\phi_s
=-2z\widehat F_\theta'+2z\widehat F_\theta'=0.
\]

This proves graph invariance, not the PDE residual equation. Smooth activations must provide the derivative order used by the strong residual. A generic ReLU profile does not provide a classical third derivative at its breakpoints; a weak formulation would require a different stated contract.

If instead independent network channels represent \((\widehat F,\widehat P,\widehat C)\), define
\(r_1=\widehat F'-\widehat P\), \(r_2=\widehat P'-\widehat C\). Differentiation gives

\[
\widehat F''-\widehat C=r_1'+r_2,
\qquad
\widehat F'''-\widehat C'=r_1''+r_2'.
\tag{3.12}
\]

Small function values of \(r_1,r_2\) do not bound their derivatives. This explains why a small first-order state loss need not control the original scalar third-order residual or the actual initial trace of \(\widehat F\). Derivative-compatible single-F architectures remove this particular representation defect, but do not guarantee successful training.

If a positive slope is required, one possible representation is \(\widehat\mu=e^{S_\theta}\), \(\widehat F=F_0+\int\widehat\mu\,dz\). To match \(\mu(z_0)=P_0>0\) and \(\mu'(z_0)=C_0\), enforce
\(S(z_0)=\log P_0\) and \(S'(z_0)=C_0/P_0\), since \(\mu'=e^SS'\). Its integral and derivative costs must be counted. Positivity of one field does not verify the other guards or equations.

For a residual loss, define the linearization

\[
\ell_{\mathcal R,F}(\delta F)
=\sum_{j=0}^{n}\frac{\partial\mathcal R}{\partial F^{(j)}}D_z^j\delta F.
\]

With fixed symmetric weight W and fixed measure, the residual contribution to a directional gradient is

\[
D_\theta\mathcal L[\delta\theta]
=2\int\ell_{\mathcal R,\widehat F}
 (\chi_KD_\theta N_\theta[\delta\theta])^T
 W\mathcal R[\widehat F]\,dz.
\tag{3.13}
\]

Include data terms and any derivatives of W or of a profile-dependent measure. A pullback of equations may preserve zeros while changing residual magnitudes and integration weights. Those changes must be derived, not inferred from a similarity variable alone.

Approximation existence, optimizer convergence, sampled residual accuracy, continuous residual bounds, and physical solution error are separate claims. Derivative-norm approximation results for tanh networks address the first under their assumptions [6]. They do not prove that a particular width, optimizer, or training budget achieves that approximation.

### 3.7 Convert a residual bound into a conditional error bound

Let the exact and approximate first-order states stay in a common regular region where f is L-Lipschitz. Define

\[
e(z)=\widehat Y(z)-Y(z),\quad
r(z)=\widehat Y'(z)-f(z,\widehat Y(z)),\quad e_0=\|e(z_0)\|.
\]

Subtract their integral equations:

\[
e(z)=e(z_0)+\int_{z_0}^{z}
 \{f(\zeta,\widehat Y(\zeta))-f(\zeta,Y(\zeta))+r(\zeta)\}\,d\zeta.
\]

Taking norms yields

\[
\|e(z)\|\le e_0+\int_{z_0}^{z}\{L\|e(\zeta)\|+\|r(\zeta)\|\}\,d\zeta.
\]

Define the right-hand side as v(z), so \(\|e(z)\|\le v(z)\) and
\(v'\le Lv+\|r\|\). Multiply by \(e^{-L(z-z_0)}\), integrate, and obtain

\[
\boxed{\|e(z)\|\le e^{L(z-z_0)}e_0+
 \int_{z_0}^{z}e^{L(z-\zeta)}\|r(\zeta)\|\,d\zeta.}
\tag{3.14}
\]

If \(\|r\|_\infty\le\varepsilon\) on an interval of length b, this gives

\[
\|e\|_\infty\le
\begin{cases}
e^{Lb}e_0+(e^{Lb}-1)\varepsilon/L,&L>0,\\
e_0+b\varepsilon,&L=0.
\end{cases}
\tag{3.15}
\]

The derivation is a standard conditional IVP stability estimate, not a new general theorem. It requires trajectory containment and a continuous residual bound. A reference-trajectory box does not automatically contain a trained approximant. Dense independent sampling is useful evidence but does not prove a supremum bound. Interval enclosures, validated polynomial bounds, or a justified derivative/covering estimate are needed for such a certificate. A BVP requires a separate stability argument.

For the directly reconstructed class (2.45), a state defect \((r_H,r_a,r_C)\) gives the exact original residuals

\[
\Delta_1^{\mathrm c}=x^2r_H,\quad
\Delta_2^{\mathrm c}=x^3(\widehat a\,r_H+\widehat H\,r_a),\quad
\Delta_3^{\mathrm c}=x^2r_C.
\tag{3.16}
\]

At matched physical x in a bounded interval, field errors satisfy

\[
\|(\widehat h-h,\widehat u-u,\widehat b-b)\|_\infty
\le\max\{x_2^2,x_2\}\,\|\widehat Y-Y\|_\infty,
\]

with an identical bed gauge and the dimensionless max norm. This constant is specific to this reconstruction.

For material reconstruction, even at a matched label s,

\[
\left|\frac1{\widehat q}-\frac1q\right|
=\frac{|\widehat q-q|}{|\widehat q q|}
\le q_{\min}^{-2}|\widehat q-q|
\]

requires both slopes to exceed a positive \(q_{\min}\). At a fixed physical x, let \(s=\phi^{-1}(t,x)\), \(\widehat s=\widehat\phi^{-1}(t,x)\) in a common image. The mean value theorem gives

\[
|\widehat s-s|\le q_{\min}^{-1}\|\widehat\phi-\phi\|_\infty.
\]

Then, for example, velocity error also contains
\(\operatorname{Lip}_s(v)|\widehat s-s|\), in addition to the matched-label velocity error. Bed reconstruction needs its primitive and gauge bounds too. These are the missing implications in any argument that jumps directly from a scalar PINN loss to physical field accuracy.

### 3.8 Benchmark progressively and retain negative evidence

The useful comparison is a sequence of matched mathematical tasks:

| Stage | Method | Question |
| --- | --- | --- |
| C0 | Exact/quadrature solution or accurate ODE solve | What accuracy and cost already suffice for one problem? |
| C1 | Cached solution, Chebyshev/spectral reuse, classical parameter surrogate | Can deterministic reuse serve repeated queries? |
| N0 | Standalone reduced-ODE PINN | Can direct learning meet the same state, derivative, data, and residual requirements? |
| H1 | Analytical prior plus compatible neural correction | Does removing known structure improve the measured result? |
| H2 | Conditional hybrid on a declared parameter/data family | Does the benefit hold for entire held-out profiles? |
| O1 | Proposed symbolic integral/ODE-symmetry discovery | Does an exact certificate actually lower order, at useful search-plus-verification cost? |

Freeze model IDs, dimensionless ranges, branches, data, intervals, errors, budgets, and failure categories. Use multiple seeds for neural runs and whole-profile splits for conditional models. Separate observations, reference-generated labels, and collocation information. Include all completed runs and budget failures. A fair classical family surrogate can fail too; record that result rather than assuming every deterministic baseline succeeds.

For each proposed improvement, state its mechanism and an ablation: additional equation-derived prior versus data lifting alone; compatible derivatives versus independent channels; known first-integral formulation versus the differentiated equation; regular coordinate choice; or a deterministic corrector/fallback. An architecture change must address a diagnosed defect. Greater architectural complexity does not itself establish stronger mathematical reasoning.

With shared symbolic cost \(C_{\rm sym}\), a representative many-query accounting is

\[
\begin{aligned}
C_{\rm classical}(N_q)&=C_{\rm sym}+N_qC_{\rm solve},\\
C_{\rm hybrid}(N_q)&=C_{\rm sym}+C_{\rm offline}
+N_q(C_{\rm inference}+C_{\rm check}+C_{\rm correction}
+p_{\rm fallback}C_{\rm fallback}).
\end{aligned}
\tag{3.17}
\]

Offline cost includes data generation, base construction, tuning, training, and validation. A classical reusable representation has its own offline/online model. A break-even count is meaningful only when both methods meet the same accuracy/failure requirements and the online saving is positive. Fast inference of an inaccurate profile is not a speedup at matched accuracy.

Its first 17 runs and six derivative-compatible follow-ups have separate frozen/exploratory status. The older 40 fixed-feature coefficient fits and 66 historical PINN/PIKAN runs are separate studies [R; D, Sections 11–12, pp. 44–48]. These observations favor classical solution/reuse for those tested tasks. They do not establish a universal neural impossibility, a continuous learned-error enclosure, or success of the proposed first-integral learner.

PINNacle and failure-mode studies inform a comparison protocol; a PDE benchmark is not automatically a reduced-ODE benchmark or an existence theorem [7–8]. The present task learns a profile or proposes structure for a fixed known law. Learning an unknown component of a universal differential equation is a different modeling problem [9].

## Appendix A. Executable symbolic replication

Save the following block as `workflow_checks.py` in an environment with SymPy 1.14.0, then run `python workflow_checks.py`. The code uses exact rational arithmetic. Rational denominators and real-power arguments retain the guards specified in the main text; positive-velocity substitutions are applied after differentiation when checking noninteger-power expressions. The script does not train a network or rerun the external project campaign.


```python
"""Exact checks for workflow.md. Requires SymPy 1.14.0; no research runs replayed."""
import json
import sympy as S

checks = {}
def zero(name, expression):
    reduced = S.factor(S.cancel(S.together(expression)))
    checks[name] = reduced == 0
    if reduced != 0:
        raise AssertionError((name, reduced))

t, x, z, g, beta, kap = S.symbols('t x z g beta kappa', positive=True)
m = S.symbols('m', real=True)
F, P, C, K = S.symbols('F P C K', real=True)
V = F-z*P
def D(expr):
    return S.diff(expr,z)+P*S.diff(expr,F)+C*S.diff(expr,P)+K*S.diff(expr,C)

# Independent polynomial collection for the general first-order system.
r = S.Matrix(S.symbols('r1:4'))
f = S.Matrix(S.symbols('f1:4'))
A = S.Matrix(3,3,S.symbols('A0:9'))
Eta = S.Matrix(3,3,S.symbols('E0:9'))
ta = S.Matrix(1,3,S.symbols('tau1:4'))
xi = S.Matrix(1,3,S.symbols('xi1:4'))
et = S.Matrix(S.symbols('et1:4'))
ex = S.Matrix(S.symbols('ex1:4'))
XA = S.Matrix(3,3,S.symbols('XA0:9'))
Xf = S.Matrix(S.symbols('Xf1:4'))
tt,tx,xt,xx = S.symbols('tau_t tau_x xi_t xi_x')
k = f-A*r
scalar = lambda row,col:(row*col)[0]
direct = et+Eta*k-k*(tt+scalar(ta,k))-r*(xt+scalar(xi,k))+XA*r+A*(ex+Eta*r-k*(tx+scalar(ta,r))-r*(xx+scalar(xi,r)))-Xf
constant = et+Eta*f-f*(tt+scalar(ta,f))+A*ex-A*f*tx-Xf
linear = -Eta*A+A*Eta+XA+(tt+scalar(ta,f)-xx)*A-(xt+scalar(xi,f))*S.eye(3)+tx*A*A+f*(ta*A)-(A*f)*ta
quadratic = -(A*r)*scalar(ta,A*r)+r*scalar(xi,A*r)+(A*A*r)*scalar(ta,r)-(A*r)*scalar(xi,r)
for i in range(3):
    zero('general determining collection component '+str(i+1),(direct-constant-linear*r-quadratic)[i])

# Diagonal-basis quadratic identity used to derive projectability.
lam = S.symbols('lambda1:4')
Ad = S.diag(*lam)
Nd = -(Ad*r)*scalar(ta,Ad*r)+r*scalar(xi,Ad*r)+(Ad*Ad*r)*scalar(ta,r)-(Ad*r)*scalar(xi,r)
for i in range(3):
    expression = r[i]*sum((lam[i]-lam[j])*(lam[i]*ta[j]-xi[j])*r[j] for j in range(3))
    zero('eigenbasis quadratic component '+str(i+1),Nd[i]-expression)

# General-m current reduction: common scaling, in both scalar models.
A0 = (z*z*P-g/P**2)*C
J0 = -beta*z*V**(m-1)*C/P
LP = -z**3*P+g*z/P**2+g*beta*z*V**(m-1)/P
LM = -F*z*z+g*F/P**3+g*beta*z*V**(m-1)/P
RP = -A0-z*D(A0)-g*D(J0)
RM = RP-D(V*A0/P)
zero('printed common-scaling first integral',RP-D(LP*C))
zero('material common-scaling first integral',RM-D(LM*C))
data = {z:1,F:2,P:S.Rational(1,2),C:S.Rational(1,10),g:1,beta:S.Rational(1,10),m:3}
for label,L,third in [('P',LP,-S.Rational(11,395)),('M',LM,S.Rational(98,1445))]:
    rhs = -(S.diff(L,z)+P*S.diff(L,F)+C*S.diff(L,P))*C/L
    zero(label+' initial third derivative',rhs.subs(data)-third)

# Explicit cubic original-system invariant class, distinct from the report's affine class.
H,a,b,Hp,ap,bp = S.symbols('H a b Hprime aprime bprime', real=True)
mass = x*x*(Hp+3*a*H)
momentum = x**3*(a*Hp+H*ap+4*H*a*a+2*g*H*H+2*g*H*b)
exner = x*x*(bp+beta*a**3)
zero('conservative/primitive momentum identity',momentum-x*a*mass-x**3*H*(ap+a*a+2*g*(H+b)))
ode = {Hp:-3*a*H,ap:-a*a-2*g*(H+b),bp:-beta*a**3}
for label,e in [('mass',mass),('momentum',momentum),('Exner',exner)]:
    zero('original-system '+label,e.subs(ode))
amp = (3-4*g*beta)/(27*g)
ht = amp*x*x/t**2
ut = 2*x/(3*t)
bt = 4*beta*x*x/(27*t**2)
for label,e in [
    ('exact mass',S.diff(ht,t)+S.diff(ht*ut,x)),
    ('exact momentum',S.diff(ht*ut,t)+S.diff(ht*ut**2+g*ht**2/2,x)+g*ht*S.diff(bt,x)),
    ('exact Exner',S.diff(bt,t)+beta*ut**2*S.diff(ut,x))]:
    zero(label,e)

# X5 cubic scalar profile, derivative collection, and reciprocal Abel chart.
chi = 4*(g*beta-1)
A5 = 2*z*P**2+(4*z*z*P-g/P**2)*C
B5 = 8*beta*z*z*P*(P+z*C)
R5 = 2*z*D(A5)-g*D(B5)
braces = P*(chi*z*z*P**3+g)*K+(chi*z*z*P**3-2*g)*C*C+(20*g*beta-12)*z*P**4*C+(8*g*beta-2)*P**5
zero('X5 expanded scalar ODE',R5+2*z*braces/P**3)
sig,M,N = S.symbols('Sigma M N', real=True)
den = g+chi*sig**3
pol = (chi*sig**3-2*g)*M*M+(20*g*beta-12)*sig**4*M+(8*g*beta-2)*sig**5
ratio = (S.Rational(5,3)*M-pol/(sig*den))/(M+S.Rational(2,3)*sig)
reciprocal_rhs = -N**2*(ratio+S.Rational(2,3))
reciprocal_rhs = reciprocal_rhs.subs(M,1/N-S.Rational(2,3)*sig)
abel = (chi*sig**3-2*g)/(sig*den)*N+(g+8*(2*g*beta+1)*sig**3)/(3*den)*N*N+2*sig*(g+(4*g*beta-1)*sig**3)/(9*den)*N**3
zero('reciprocal Abel coefficient collection',reciprocal_rhs-abel)
Aamp = S.symbols('Aamp', positive=True)
f = Aamp*z**S.Rational(1,3)
power_residual = R5.subs({P:S.diff(f,z),C:S.diff(f,z,2),K:S.diff(f,z,3)})
zero('cubic power exact branch',power_residual.subs(beta,(1-27*g/Aamp**3)/(4*g)))

# Traveling printed model, including corrected equations (30)--(31).
speed,drift = S.symbols('c d', real=True)
v = drift-speed*P
B = speed**2*P-g/P**2-g*beta*v**(m-1)/P
Bt_expected = speed**2+2*g/P**3+g*beta*(speed*(m-1)*v**(m-2)/P+v**(m-1)/P**2)
vpositive = S.symbols('vpositive', positive=True)
zero('traveling coefficient derivative',(S.diff(B,P)-Bt_expected).subs(drift,vpositive+speed*P))
I0 = S.symbols('I0', real=True)
Msol = I0/B
zero('traveling linear first-order solution',(S.diff(Msol,P)+S.diff(B,P)*Msol/B).subs(drift,vpositive+speed*P))
bcoef = 1-g*beta
Y = bcoef*P*P/2+g/P
zero('traveling cubic primitive',S.diff(Y,P)-B.subs({speed:-1,drift:0,m:3}))
Qprim = bcoef*P**3/(3*I0)-g*S.log(P)/I0
zero('traveling F quadrature derivative',S.diff(Qprim,P)-P*(bcoef*P-g/P**2)/I0)

# State-channel derivative compatibility identity.
zz = S.symbols('zz')
ff,pp,cc = (S.Function(n)(zz) for n in ('fhat','phat','chat'))
r1 = S.diff(ff,zz)-pp
r2 = S.diff(pp,zz)-cc
zero('third-derivative compatibility',S.diff(ff,zz,3)-S.diff(cc,zz)-S.diff(r2,zz)-S.diff(r1,zz,2))

# All eight listed point fields of the free-particle equation.
yy,yp = S.symbols('Y Yprime')
fields = [(1,0),(0,1),(0,zz),(zz,0),(0,yy),(yy,0),(zz**2,zz*yy),(zz*yy,yy**2)]
for j,(xxi,eeta) in enumerate(fields):
    identity = S.diff(eeta,zz,2)+(2*S.diff(eeta,zz,yy)-S.diff(xxi,zz,2))*yp+(S.diff(eeta,yy,2)-2*S.diff(xxi,zz,yy))*yp**2-S.diff(xxi,yy,2)*yp**3
    zero('free-particle generator '+str(j+1),identity)

print(json.dumps({'sympy':S.__version__,'passed':sum(checks.values()),'total':len(checks),'checks':checks},indent=2))
```
