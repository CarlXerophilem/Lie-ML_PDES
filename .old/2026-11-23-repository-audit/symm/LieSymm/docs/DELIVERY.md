## 论文解的实际范围

论文打印标量模型 P 有错误的展开式及调换的约化变量。因此保留打印式，
给出反例，同时从原 PDE 重新计算约化式。这里的“校正约化”仍针对 P，
不等于改用 advectively corrected 模型 M，也不直接给出 Eulerian E 的解。

| 对象 | 本轮交付 |
|---|---|
| 论文九个小节 | 全部登记；3.1 为零速恒等族，3.2 分母无定义，3.3 无不变图，3.7 为任意剖面恒等族 |
| 式 (24)–(34) | 十一个编号公式逐项审计；保留精确反例及限定 |
| 行波 3.6／3.9 | 正则分支的精确参数积分表达式，保留自由积分常数及零积分常数的仿射分支 |
| 3.8 | 正确不变图上的完整二次时间剖面 |
| 标度 3.4／3.5 | 精确特解、六阶局部级数、数值剖面；一般闭式通解及奇异层延拓未解决 |
| 数值演示 | 五类有效 ODE，m=1,1.5,2,3,4；3.5 仅 m=3，共 21 个构造初值问题通过 |
| 图形 | 五个数值曲面加一个精确幂律曲面，s/t/phi 三轴；PNG、PDF、NPZ 及 HTML 入口 |

最终本机演示：`build/lie-symm-library-20261021/scalar-demo-final/index.html`。
`s` 是物质坐标，`t` 是时间，`phi` 是粒子位置；曲面不是水深图。
例如在 g=1、kappa=1/30、m=3 下，精确特解为
`phi=45^(1/3)*s^(1/3)*t^(2/3)`，取 s,t>0，原 P 残差严格为零。
它属于 X4 的奇异最高导数系数支，程序没有对零系数做除法。
