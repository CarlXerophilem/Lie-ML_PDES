# One-dimensional subalgebras from the actual adjoint matrices

This is a classification of **lines in the supplied symmetry algebra** under
the connected inner adjoint action. It is a separate result from maximal
point-symmetry classification. Completeness and nonredundancy are proved below
for the supported diagonal semidirect structure; the release status remains
`pending_fresh_review` until the independent review accepts this argument.

The equivalence relation is

\[
\langle Y\rangle\sim\langle \operatorname{Ad}(g)Y\rangle,
\qquad g\text{ in the connected group generated by the supplied algebra}.
\tag{1}
\]

A nonzero scalar multiple gives the same line. No disconnected transformation
or outer automorphism is added to (1). Thus a sign or continuous ratio that
cannot be changed by (1) is retained. This document does not classify
subalgebras of dimension two or more, and it does not start the two-dimensional
PDE stage. Every line is a Lie subalgebra because `[Y,Y]=0`.

## 1. The software obtains, rather than prescribes, the adjoint action

Given the actual solved basis `e_1,...,e_N`, `adjoint_structure` calls the
parent's bracket computation, solves its constant structure coefficients,
and forms

\[
(\operatorname{ad}_{e_i})_{kj}=c_{ij}^{\ k},\qquad
[e_i,e_j]=\sum_k c_{ij}^{\ k}e_k.
\tag{2}
\]

Every column is reconstructed as a vector field and checked against a direct
bracket. The convention is exactly

\[
\operatorname{ad}_X(Y)=[X,Y],\qquad
\operatorname{Ad}(\exp(\varepsilon X))=\exp(\varepsilon\operatorname{ad}_X).
\tag{3}
\]

The adapter then identifies constant-coordinate basis vectors and homogeneous
diagonal basis vectors. It **checks** that they give a decomposition

\[
\mathfrak g=V\rtimes A,\qquad [V,V]=[A,A]=0,
\qquad [A_j,V_i]=W_{ij}V_i.
\tag{4}
\]

It returns `unresolved` when this presentation or its bracket closure cannot
be verified. It neither substitutes a familiar abstract algebra nor silently
changes a non-diagonal basis to an assumed eigenbasis. Permutations and
nonzero rescalings of the supplied basis do not require a fixed basis order.

For reference, naming the three translation generators
`T=partial_t`, `X=partial_x`, `Z=partial_B`, the actual SVE computations give:

| Supplied algebra | Diagonal directions | Rows of `W`, ordered `T,X,Z` |
| --- | --- | --- |
| Generic positive-transport, `G=0` | `C=t partial_t+x partial_x` | `(-1),(-1),(0)` |
| Cubic positive-transport, `G=0`, or zero transport | `C` and `R=t partial_t-2h partial_h-u partial_u-2B partial_B` | `(-1,-1),(-1,0),(0,2)` |
| Generic positive-transport, `G>0,m!=3` | none | three empty rows |
| Cubic slope branches or slope-only family | `D_n` from the slope classification | `(2-n),(1-n),(-2)` |

These entries are explanatory output of (2), not tables fed into the
representative-generation algorithm. Model-parameter guards still come from
the parent classification branch; this module classifies whichever algebra
the caller supplies and does not independently certify its maximality.

## 2. Derive the complete orbit action before selecting representatives

Write `Y=v+a`, with coordinate vectors `v` in `V` and `a` in `A`. Since the
two subspaces are abelian and the action is diagonal, direct exponentiation
of the block matrices in (2) gives

\[
\begin{aligned}
\operatorname{Ad}(\exp w)(v+a)&=v-\operatorname{diag}(Wa)w+a,
&&w\in V,\\
\operatorname{Ad}(\exp s)(v+a)&=\operatorname{diag}(e^{Ws})v+a,
&&s\in A.
\end{aligned}\tag{5}
\]

For the first formula `ad_w` has square zero, so its exponential is exactly
`I+ad_w`. The minus sign follows from `[w,a]=-[a,w]`. The code's witness tests
use `exp(actual_ad_matrix)` and independently check this sign.

Products of (5) exhaust the connected inner action: the vector fields of `A`
preserve the ideal `V`, so a product of elementary exponentials can be
reordered into one `V` exponential and one `A` exponential. Equation (5)
shows that:

1. The projection onto `A` is unchanged by every inner transformation.
2. If `a=0`, a translation acts trivially, and positive diagonal scaling is
   the only nontrivial action on `v` before rescaling the line.
3. If `a!=0`, every component with `(Wa)_i!=0` can be removed using
   `w_i=v_i/(Wa)_i`. A component in the zero-weight kernel cannot be removed
   this way.

All divisions in item 3 are recorded with their nonzero eigenvalue guards.
The parameter splitting below prevents a vanishing eigenvalue from being
divided out.

## 3. Translation-only lines: support, signs, and log magnitudes

For a nonzero translation vector, let `S` be its nonzero support. Positive
diagonal factors preserve `S` and each sign. A negative rescaling of the line
flips all signs, so choose the first supported coefficient positive. There
remain exactly `2^(|S|-1)` sign choices.

Put `y_i=log|v_i|` on `S`. The connected adjoint action and positive line
rescaling act by

\[
y\longmapsto y+M_S\theta,
\qquad M_S=[\mathbf 1\mid W_S],\quad
\theta=(\log|q|,s_1,\ldots,s_r)^T.
\tag{6}
\]

This converts the positive-magnitude orbit problem into exact linear algebra.
The implementation selects independent rows `P` of `M_S` and independent
columns `J` of those rows. The square minor `N=M_S[P,J]` is required nonzero.
With `E_P` the row-selection matrix, set

\[
\theta_J=-N^{-1}E_Py,\quad \theta_{J^c}=0,\qquad
\Pi=I-M_S[:,J]N^{-1}E_P.
\tag{7}
\]

Then the canonical log magnitudes are `Pi y`. The selected rows become zero,
so their magnitudes become one. Every other row is a continuous invariant,
represented by an independent positive parameter `rho=exp((Pi y)_i)`.

The machine-readable certificate retains the chosen minor, its nonzero guard,
all vanishing higher minors, the normalization map, and exact checks of

\[
\Pi M_S=0,\qquad \Pi^2=\Pi,\qquad E_P\Pi=0.
\tag{8}
\]

The columns of `Pi` indexed by the unselected rows contain the corresponding
identity block: the row selection in (7) has zero entries in those columns.
Thus its rank is `|S|-rank(M_S)`. Its kernel has exactly the dimension of
`im(M_S)`, and (8) proves that these two spaces are equal. Consequently two
translation lines lie in the same orbit **if and only if** their supports,
oriented sign patterns, and retained log magnitudes agree. This proves both
coverage and nonredundancy of the generated families; it is not a sampled
orbit search.

The algorithm enumerates each nonempty support, each oriented sign pattern,
and the required positive continuous parameters. It outputs 13 families for
three translations: three single supports, six signed pairs, and four signed
triple supports. The number of continuous parameters in a family varies with
the actual matrix rank. In particular:

* For an abelian three-dimensional algebra, `rank(M_S)=1`, so a full-support
  family has **two** independent positive ratios. Reducing every coefficient
  to `0,1,-1` would be incorrect.
* For `C` alone, `T` and `X` have the same weight. Their nonzero ratio is a
  continuous invariant. With all three translations supported, representatives
  can be written `T+epsilon*rho*X+delta*Z`, with `rho>0` and independent signs.
* For `C,R`, the full-support matrix in (6) has determinant `-1`, so every
  nonzero magnitude can be normalized. There are no translation-only
  continuous moduli on any support.

## 4. Lines with a nonzero scaling projection

Normalize the first nonzero coefficient of `a` to one by the **unique** line
rescaling. Its projective direction is unchanged by all inner transformations.
For each direction, (5) removes exactly the translation components with
nonzero `(Wa)_i`. Let `K(a)` be the zero-weight indices.

The remaining action on a supported subset `S` of `K(a)` is positive diagonal
scaling with matrix `W_S`. Apply the same construction (7), now with

\[
M_S=W_S\quad\text{rather than }[\mathbf1\mid W_S].\tag{9}
\]

There is no additional line factor: it would destroy the chosen normalization
of `a`. Therefore **all** `2^|S|` sign choices must be retained. Include the
empty support, which represents the pure scaling direction. The support,
signs and projected log magnitudes again give an if-and-only-if orbit test.

This also proves that prior translations cannot secretly alter a surviving
kernel component: they leave it unchanged in (5), and conjugation by an `A`
exponential merely multiplies it by the already-accounted positive factor.

For one scaling direction, normalize its coefficient to one. A zero-weight
translation is central under the entire `A`, so its coefficient is an actual
continuous real modulus. For example, `C+cZ`, `c in R`, cannot be collapsed to
just `C`, `C+Z`, `C-Z`. The implementation represents this disjointly as
`C`, `C+rho Z`, `C-rho Z`, `rho>0`.

For two scaling directions, normalize `a=(1,rho)` when its first coefficient
is nonzero, and use the separate projective chart `a=(0,1)` otherwise. The
algorithm computes all roots of each row of `W(1,rho)^T`; it does not assume
which directions are exceptional. For the actual `C,R` algebra this gives:

\[
\begin{array}{ll}
C+\rho R,&\rho\in\mathbb R\setminus\{0,-1\},\\
C+\epsilon Z,&\epsilon\in\{-1,0,1\},\\
C-R+\epsilon T,&\epsilon\in\{-1,0,1\},\\
R+\epsilon X,&\epsilon\in\{-1,0,1\}.
\end{array}\tag{10}
\]

The second independent scaling can normalize the magnitude of the one
surviving translation in each exceptional direction. That is why only signs
remain in (10), whereas a central translation with only one scaling retains
a continuous modulus. There are ten nonzero-`A` representative families in
(10), in addition to the thirteen translation families.

## 5. Slope-family parameter strata are not interchangeable

The actual adjoint weights are

\[
\lambda_T=2-n,\qquad\lambda_X=1-n,\qquad\lambda_Z=-2.
\tag{11}
\]

For one scaling direction, every required rank change in (6) occurs when a
pair of weights is equal; every new kernel in (5) occurs when a weight is zero.
The software therefore solves the actual eigenvalue and pairwise-difference
equations. On the requested interval `0<=n<=4` their union is precisely

\[
n\in\{1,2,3,4\}.\tag{12}
\]

The generic stratum retains the closed interval constraint and excludes all
four values; each value is a separate singleton stratum. The endpoint `n=0`
belongs to the generic stratum because none of these weights or differences
vanishes there. The mechanisms are different:

| Parameter | What changes | Required retained modulus |
| --- | --- | --- |
| `n=1` | `lambda_X=0` | `D_1+cX`, arbitrary real `c` |
| `n=2` | `lambda_T=0` | `D_2+cT`, arbitrary real `c` |
| `n=3` | `lambda_X=lambda_Z` | nonzero `X,Z` translation ratio |
| `n=4` | `lambda_T=lambda_Z` | nonzero `T,Z` translation ratio |

On full translation support, `lambda_T-lambda_X=1` never vanishes. The pivot
rows can always be `T,X`, giving representatives

\[
T+\epsilon X+\delta\kappa Z,\qquad
\kappa>0,\quad \epsilon,\delta\in\{-1,1\},\tag{13}
\]

where the continuous invariant of an original vector is

\[
\kappa=|v_Z|\,|v_T|^{3-n}|v_X|^{n-4}.
\tag{14}
\]

Formula (14) is obtained from the projector (7). It is not used as a preset
normalization formula. At `n=3` it becomes `|v_Z|/|v_X|`, and at `n=4` it
becomes `|v_Z|/|v_T|`. Pair supports inherit the corresponding additional
modulus exactly at these equal-weight parameters. Away from `n=1,2`, a line
with nonzero scaling projection reduces to the pure `D_n` direction.

## 6. Interfaces, validation scope, and explicit limitations

```python
classify_subalgebra_lines(coordinates, basis, parameter=None, domain=None)
adjoint_structure(coordinates, basis)
adjoint_action(structure, coordinates_of_X, coordinates_of_Y, epsilon=1)
canonicalize_translation_line(structure, coefficients)
```

For the continuous slope-only algebra use `parameter=n,domain=Interval(0,4)`.
Fixed cubic branches and first-order branches need no weight parameter.
Success has `status='certified_line_orbit_classification'`; `strata` stores
every parameter stratum and its `families`. Each family includes actual
vector-field coefficients, parameter domains and its rank/projector witness.
`review_status='pending_fresh_review'` is separate from symbolic identity
verification and from the parent's maximal point-algebra gate.

`canonicalize_translation_line` also returns a concrete orbit witness built
with the matrix exponential of the **actual** adjoint matrices. Unknown
support or undecidable real signs return `unresolved`. The generic classifier
returns `unresolved` for an undeclared symbolic weight parameter, multiple
weight parameters, more than two diagonal directions, or an unsupported
non-diagonal presentation. Such a result is a backend limitation, not an
obstruction to mathematical classification.

Run the regression tests from the project root:

```powershell
python -B -m pytest -q -p no:cacheprovider build/sve-general-symm-20261020/tests/test_subalgebras.py
```

The tests cover every declared one-dimensional PDE algebra, actual adjoint
signs, all four slope resonances, central continuous moduli, the projective
two-scaling charts, exact orbit witnesses, preservation of unequal continuous
invariants, and explicit unsupported results. No random orbit sample is used
as the completeness proof; completeness is the necessary-and-sufficient
normal-form argument (5)--(9).

An optimal system under (1) does not imply useful reduction for every member.
For example, a pure bed translation has zero projected base rank and cannot
by itself remove an independent variable. Initial/boundary-data compatibility,
regular reconstruction charts and singular reduced equations remain separate
checks. Nor does this classification establish maximality of the supplied
point algebra, a global group action, or disconnected equivalence classes.
