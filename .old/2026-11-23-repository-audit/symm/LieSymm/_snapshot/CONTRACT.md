# General-symm SVE implementation contract

Implement the user-approved pipeline, with readable numbered derivations from arbitrary point-generator coefficients. Main input is a PDE system, parameters and regularity/data conditions, not a prescribed list of generators.

## Scope and stage gates

On h>0 and nonzero speed, classify the local smooth Lie point algebra of the full evolving-bed SVE system. g>0, K,G>=0, 1<=m<=4; slope laws n=m-1 and n=m. At K=0,G>0 classify the deduplicated n in [0,4]; at K=G=0 remove m,n. Primitive/conservative fields are related by a point map. Material coordinates and printed/corrected scalar controls are separate objects.

1. Audit and repair the parent design in this new directory, preserving original files.
2. Complete all declared 1D classification branches, necessary and sufficient equations, coverage, equivalence evidence and independent review.
3. Only after gate 2 passes, extend to all declared 2D branches including constant f=0 and f!=0.
4. Only after gate 3 passes, run the recorded 64-candidate conditional search and export verified ML inputs. No training campaign is authorized by this cycle.

An incomplete necessary-equation integration or unproved parameter-coverage exclusion does not unlock the next stage. Only explicitly verified equivalence maps may merge records; unknown additional equivalences leave potentially redundant records in the full coverage table. Classification of the entire disconnected point-equivalence groupoid is a separate unresolved question, not part of the user's local Lie-point-algebra completion gate. Finite ansatz solutions and finite sample tests do not prove maximality. Optimal-subalgebra completeness has its own status.

## Files and authorization

All new source, tests, derivations, source snapshots, logs and reports go under this directory. Historical sources, frozen packages, manuscripts, unrelated dirty files and bibliography are read-only. No paid calls, publication, Git mutation or scheduler. No user-specified deadline or token cap exists.

## Evidence and resources

Each branch: primary source/model -> hand derivation -> exact symbolic checks -> broken-hypothesis controls -> independent review. Record unresolved equations and every branch division. Preserve stage-level results separately from the classification gate.

One heavy symbolic process at a time (lease cpu-symbolic), with a per-process timeout recorded in its receipt. Lightweight algebra/text work may run in parallel. Timeouts trigger decomposition or a documented unresolved result, never an obstruction theorem.

Run required project audit/data-flux/workflow, relevant engine/chart tests and active package tests with outputs separated from old receipts. New code must have independent mathematical regression tests. Release only reviewed claim revisions; hash all final artifacts and initial protected inputs.
